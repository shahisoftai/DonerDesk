# See results on a map

The Maps screen shows an indicator's results by place. Open a project, choose **Data**, then **Maps**.

## Choose what to map

1. Tick the indicator and choose the measure.
2. Choose how deep to read the places: the country, or the areas inside it.
3. Choose a map type: circles that grow with the value (graduated symbols), countries coloured by value, a ranking, or a table.

A place with no value is grey or "Not measured", never zero. A rate is shown for the place that recorded it and is never added up. A place that has a value but no position on the map is named under the chart so you can pin it in **Places**.

## Keep and share

- **Save** the view for yourself or for the project.
- **Export** the picture (PNG or SVG).
- **Download for Google Earth or a GIS**: choose the places file as **KML** or **GeoJSON**. Only places with a position are included; a place with no recorded value is written as "no value recorded".

The maps use the geography built into DonorDesk. Nothing about a place is sent to an outside map service.
