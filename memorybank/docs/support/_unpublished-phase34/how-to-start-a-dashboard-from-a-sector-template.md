# Start a dashboard from a sector template

A sector template is a ready-made dashboard for a kind of programme: water, sanitation and hygiene, health, nutrition, education, food security, or protection. It is a starting point you can change completely.

## Make a dashboard from a template

1. Choose **Dashboards** in the left menu, then **Start from a sector template**.
2. Choose a template and a project, then **Use this template**.
3. The template asks for **roles**, such as "people trained" or "coverage rate". For each role, choose one of the project's indicators. The page suggests a match when the words fit, but you decide.
4. Choose who sees the dashboard and give it a name, then create it.

If you leave a role without an indicator, the charts that need it are left out and listed by name. If nothing can be drawn, nothing is created.

## After that

The new dashboard is an ordinary dashboard. Move, resize, remove or add charts, add notes, split it into tabs, and share it. See "Use tabs, full screen and print on a dashboard".
