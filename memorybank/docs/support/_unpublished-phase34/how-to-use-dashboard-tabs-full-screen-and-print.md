# Use tabs, full screen and print on a dashboard

## Split a dashboard into tabs

1. Open the dashboard and choose **Edit**.
2. Open **Tabs**. Each chart has a box for its tab name. Type a name to put the chart on that tab; typing a new name makes a new tab. Leave a chart's box empty to keep it on the first tab (shown as **Overview**).
3. Choose **Save**.

A dashboard can have up to eight tabs, and a tab name can be up to 40 characters. The tab bar also appears on a shared read-only link.

## Show it on a wall screen

Choose **Full screen**. The dashboard fills the screen and refreshes itself every minute, so the figures stay current. Press Esc or choose **Leave full screen** to go back.

## Print

Choose **Print**. Only the dashboard is printed, without the menus; charts are not split across pages. The tab you are looking at is the one that prints.

## Look at one project

A dashboard with charts from more than one project has a **Show one project** list. It changes only what you see. It is not saved.
