# Build a chart in the Chart Studio

The Chart Studio draws a chart from the results you have recorded in a project. It keeps the settings of the chart, not the figures: each time you open a chart it is drawn again from the latest values.

## Open it

Open a project, choose **Data**, then **Chart Studio**.

## Choose what to show

1. Under **Data shown**, choose what the chart is about: one indicator over time, several indicators, the latest progress, baseline, target and result, the status of the data, finance, the work plan, or results by place.
2. Tick the indicators on the left. Choose **what to measure** (the value for each period, the cumulative value, or the percent of target) and the periods to include.
3. Choose a type. Types that cannot show this data are greyed out, and the tooltip says why (for example, a pie needs parts of a whole).

If a chart would mislead (for example, two different units on one axis, or a rate stacked like a count), the Studio says so in a sentence and, where it can, offers a one-click fix.

## Change how it looks

Use the panels on the right to change colours, labels, line styles, axes, a second axis, the legend, number formats and size. Add notes on the chart with annotations. Undo and redo are always available.

A missing value is shown as a gap, never as zero. Values that are not verified yet can be shown or hidden; the chart tells you how many are not verified.

## Keep it, export it, put it on a dashboard

- **Save** the chart for yourself, or share it with the project (sharing needs someone who manages projects). Each save keeps the last ten versions; you can restore an earlier one.
- **Export** as an image (PNG or SVG) or the plotted data as a spreadsheet file (CSV).
- Under **Add to a dashboard**, choose a dashboard you can change.
