# See an indicator in different ways

Open an indicator from the logframe. Under **Views of this indicator**:

- **Against target** shows the baseline, the target and the latest result together.
- **Over time** shows the value in each period, with the target.
- **By place** shows the result at each place.
- **By group** shows how the latest recorded result splits between groups, such as women and men, as a pie. A pie is drawn only for counts and amounts that add up, with at least two groups. For a rate or a percentage it says why it is not drawn.
- **Table** shows the same figures as a table.

Where the figures cannot support a view, the tab says so in a sentence instead of drawing something misleading. Choose **Open the Chart Studio** to change the chart further.
