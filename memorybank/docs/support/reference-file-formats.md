# Supported File Formats and Size Limits

## Evidence File Formats

DonorDesk accepts the following file formats for evidence upload:

| Format | Extension | Common uses |
|--------|----------|-------------|
| **PDF** | .pdf | Reports, documents, scanned files |
| **Word** | .docx, .doc | Text documents, templates |
| **Excel** | .xlsx, .csv | Data, indicator tables, attendance |
| **Image** | .jpg, .jpeg, .png | Photos, screenshots |
| **Text** | .txt | Plain text notes |

**Not currently supported:**
- Video files (.mp4, .mov, etc.)
- Audio files (.mp3, .wav, etc.)
- ZIP files (individual files only)
- CAD files (.dwg, .dxf)
- Adobe Illustrator files (.ai, .eps)

## Logframe Import Formats

When importing a logframe from a file:

| Format | Extension | Best for |
|--------|----------|---------|
| **Excel** | .xlsx, .csv | Structured logframes with indicators |
| **Word** | .docx, .doc | Text-based logframes |
| **Text** | .txt | Simple tab or comma-separated data |

## Report Export Formats

DonorDesk can export reports in these formats:

| Format | Extension | Use case |
|--------|----------|---------|
| **PDF** | .pdf | Final donor submission |
| **Word** | .docx | Editable draft for internal review |
| **Excel** | .xlsx | Indicator data tables only |
| **ZIP** | .zip | Full evidence package with all files |

## File Size Limits

| Plan | Max file size per upload |
|------|------------------------|
| Starter | 50 MB |
| Team | 100 MB |
| Growth | 200 MB |
| Enterprise | Custom (contact us) |

**Note:** Files linked from Google Drive do not have a size limit through DonorDesk — they are stored in your Drive.

## Recommended File Practices

### For photos
- Save as JPG for photos
- Save as PNG for screenshots or graphics
- Keep resolution at 1-2 MB per image — no need for print-quality files

### For documents
- PDF is preferred for documents you will not edit
- Word (DOCX) is preferred for documents you will edit
- Keep file sizes under 10 MB where possible

### For spreadsheets
- CSV is best for data import/export
- XLSX supports formatting and multiple sheets
- Keep to under 5 MB for indicator data

## Storage Limits

**Note:** Files linked from Google Drive do NOT count toward storage limits.

## Tips for Reducing File Sizes

### Photos
Use an online compressor or save at 80% quality:
- macOS: Preview → Export → adjust quality slider
- Windows: Paint 3D → Save a copy → adjust quality
- Online: Squoosh.app (free, browser-based)

### PDFs
- Remove unnecessary pages before uploading
- Use "Save as" not "Print to PDF" for smaller files
- For scanned documents, use black-and-white scanning where appropriate

### Documents
- Remove embedded images if not needed
- Use web-optimised PDF export settings
- Compress before uploading if over 10 MB
