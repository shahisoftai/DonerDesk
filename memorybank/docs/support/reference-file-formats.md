# Supported File Formats and Size Limits

## Evidence files

Common document, spreadsheet, image and text formats can be uploaded as evidence, for example PDF, Word (.docx), Excel (.xlsx) and CSV, JPG/PNG images and plain text. **Maximum size: 100 MB per file.** Files linked from Google Drive stay in Drive.

Text is read from documents so AI drafts can cite them. Scanned images and photos contain no text; add a description or a text version.

## Donor templates

Word (.docx), PDF, text (.txt), Markdown (.md), Excel (.xlsx) or CSV, up to **20 MB**. Word keeps headings and tables best. Scanned PDFs cannot be read; paste the text instead. The **mapping** wizard for donor-native output needs the original **.docx**.

## Imports

| Import | Formats |
|---|---|
| Logframe, indicators, activities | XLSX, CSV, TXT. Use **Download template** on each page. |
| Evidence records | XLSX / CSV using the evidence template |
| Indicator values | Google Sheets (URL) or pasted CSV |

## Exports

| Export | Format |
|---|---|
| Report | Word (.docx) and PDF |
| Indicator table | Excel (.xlsx) |
| Evidence checklist | Excel / document |
| Evidence pack | ZIP |

## Storage limits

Only DonorDesk-managed files count toward your storage quota (Starter 1 GB, Team 25 GB, Growth 100 GB). Drive-linked files do not. See [Plans and limits](/support/account-billing/plans-and-limits).

## Tips

- Use descriptive file names and set the reporting period on upload.
- Prefer text-based PDFs to scans.
- Compress large photos before uploading.
