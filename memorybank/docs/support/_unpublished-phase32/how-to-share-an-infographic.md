# How to Share an Infographic With a Link

A public link lets someone open one published file without signing in. The link shows the file only. It never shows the design, the project or the other files.

## Make a link

1. Publish the file you want to share (see [approve and publish](/support/how-to/approve-and-publish-an-infographic)).
2. In the **Publish** panel, find the file under **Published files**.
3. Choose how long the link works: from 1 to 90 days. The default is 30.
4. Click **Make a public link**, then copy it. The link is shown once in full; copy it at that point.

## Stop a link

In the **Publish** panel, find the link under **Public link** and click **Withdraw**. A withdrawn link answers "not available" straight away, and the panel shows "Link withdrawn". An expired link does the same, and the panel shows when a live link stops working.

## Good practice

- Share the published file, not a screenshot of the design. A file keeps its alt text and sources.
- Check the link in a private window before you send it.
- A link can be opened by anyone who has it. Do not share a link to a file that contains information you have not cleared for release.

Links to a file the visitor cannot see are answered "not available", so a link cannot be guessed.
