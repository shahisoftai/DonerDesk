# Understanding Donor Templates

A donor template is the report format that your donor requires. It defines the sections, structure, and sometimes the content requirements for your reports.

## Why Donor Templates Matter

Different donors have different requirements:
- UNHCR has its own format
- EU has another format
- USAID has yet another
- Some donors have no required format

Using the correct template ensures your reports meet donor expectations and make their review process smoother.

## What a Template Contains

### Sections

The main structure of the report:

```
1. Executive Summary
2. Project Overview
3. Progress Against Targets
4. Activities Completed
5. Challenges and Mitigation
6. Lessons Learned
7. Plan for Next Period
Annex A: Indicator Table
Annex B: Evidence Checklist
```

### Required Annexes

Documents the donor requires as attachments:
- Attendance sheets
- Photos
- Financial reports
- Procurement records

### Formatting Guidelines

Some templates include:
- Word/page limits
- Font sizes and styles
- Required sections
- Tone guidance

## Types of Templates

### Standard Templates

Provided by the donor:
- UNHCR quarterly report template
- EU annual report template
- UNICEF programme report template

Upload the donor's actual file and DonorDesk reads the structure.

### Your Own Template

If the donor does not provide a format:
- Create a template in DonorDesk
- Use a previous successful report as a guide
- Consult with your donor on requirements

### No Specific Template

If the donor has no requirements:
- Use a standard format
- Keep it professional and comprehensive
- Follow sector norms

## How DonorDesk Uses Templates

### When Creating a Reporting Period

1. Select the donor template
2. The reporting period inherits the template structure
3. Report sections match the template

### AI Report Generation

The AI uses the template to:
- Generate sections in the correct order
- Know which sections are required
- Understand donor-specific terminology
- Cite required annexes

### Compliance Checking

The compliance checklist checks:
- Required annexes are attached
- Section content is present
- Template-specific requirements are met

## Uploading a Donor Template

### Step 1: Get the Template

Obtain the template from your donor:
- Download from donor portal
- Email from programme officer
- Shared folder

### Step 2: Upload to DonorDesk

1. Go to your project → **Templates**
2. Click **Upload Template**
3. Select the file (PDF, DOCX, DOC)
4. Wait for DonorDesk to read it

### Step 3: Review Extracted Sections

DonorDesk will show the sections it found. Review:
- Are all sections captured?
- Are they in the right order?
- Are there sections you can delete?

### Step 4: Save

Click **Save Template**.

## Creating a Manual Template

If you do not have a donor file:

1. Go to **Templates**
2. Click **Create Template**
3. Add sections manually
4. Name each section
5. Save

## Template Versioning

When a donor updates their template:

1. Go to **Templates**
2. Find the existing template
3. Click **Upload New Version**
4. Select the new file
5. Review the new sections

New reporting periods will use the updated template. Old periods keep their original template version.

## Managing Multiple Templates

If you work with multiple donors:

1. Create a template for each donor
2. When creating a reporting period, select the relevant donor
3. The correct template structure is applied

## Tips for Template Management

- Keep the donor's original file name for easy identification
- Note the version and date in the template description
- Update templates when donors revise their formats
- Keep a record of which template was used for which period
