# Troubleshooting Storage and Quota Issues

## "Storage limit reached"

You have used all your DonorDesk-managed storage quota.

**Your options:**

### Option 1: Delete Old Files

1. Go to **Settings → Storage**
2. See which project uses the most storage
3. Go to that project → **Evidence**
4. Delete files you no longer need
5. Deleted files free up space immediately

### Option 2: Move to Google Drive

1. Connect Google Drive (Settings → Storage → Connect Google Drive)
2. For future uploads, use **Link from Drive** instead of uploading
3. Existing files cannot be automatically moved to Drive — download and re-upload as Drive links

### Option 3: Upgrade Your Plan

| Plan | Managed Storage |
|------|----------------|
| Starter | 1 GB |
| Team | 25 GB |
| Growth | 100 GB |
| Enterprise | Custom |

## Storage Usage Shows Wrong Amount

The storage counter is updated when files are uploaded or deleted.

**If it seems wrong:**
1. Wait a few minutes — updates can take time to reflect
2. Check that deleted files are actually removed
3. Note: Files linked from Google Drive do NOT count toward your quota

## Cannot Upload Because Storage Is Full

Even if you are under your quota, individual files may be too large:

| Plan | Max file size |
|------|--------------|
| Starter | 50 MB |
| Team | 100 MB |
| Growth | 200 MB |
| Enterprise | Custom |

**Solutions:**
- Compress large files
- Split into multiple smaller files
- Use Google Drive link instead of uploading

## What Counts Toward Storage?

| Storage Type | Uses your quota? |
|-------------|-----------------|
| Files uploaded to DonorDesk | Yes |
| Files linked from Google Drive | No |
| Evidence metadata | No |
| Project data (indicators, activities) | No |

## Where to Check Storage Usage

1. Click your name → **Settings**
2. Click **Billing** or **Storage**
3. See a breakdown by:
   - Total used
   - Per-project usage
   - Recent uploads

## Files Show as "Unavailable"

If a linked Drive file shows as unavailable:
1. The Google account may have lost access to the file
2. The file may have been deleted or moved in Google Drive
3. Go to **Settings → Storage** and reconnect Google Drive
4. Update the link in the evidence library

## Storage for Evidence vs Reports

Only uploaded evidence files count toward storage. Report exports are downloaded to your device and do not consume DonorDesk storage.
