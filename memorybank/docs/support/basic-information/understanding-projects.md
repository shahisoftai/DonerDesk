# Understanding Projects in DonorDesk

A project in DonorDesk represents a single donor-funded initiative. Everything you do in DonorDesk — from building your logframe to exporting reports — happens within a project.

## What Makes Up a Project

Each project contains:

- **Basic information** — Name, code, donor, dates, sector
- **Logframe** — Goal, outcomes, outputs, activities, and indicators
- **Evidence library** — All files and documents that prove your work
- **Activity log** — Records of what your team has done
- **Reporting periods** — Time windows for donor reports
- **Compliance checklist** — Gaps and issues to resolve
- **Team** — People who work on this project
- **Settings** — Project-specific configurations

## Creating a Project

### Step 1: Start the creation

Go to **Projects → New Project** or click **Create Project** on the dashboard.

### Step 2: Fill in the basics

| Field | What to enter | Example |
|-------|--------------|---------|
| **Project title** | Full official name of the project | "Integrated Nutrition Programme — Rohingya Response 2026" |
| **Project code** | Short internal code | "NUT-ROHINGYA-26" |
| **Donor name** | Who funds the project | "UNHCR" |
| **Implementing organisation** | Your organisation | "Humanity Aid Network" |
| **Partner organisation** | Any partner (optional) | "Local Health Foundation" |
| **Country** | Primary country of operation | "Bangladesh" |
| **Region/District** | Specific area | "Cox's Bazar" |
| **Sector** | Main sector | "Nutrition" |
| **Start date** | When the project begins | "2026-01-01" |
| **End date** | When the project ends | "2026-12-31" |
| **Reporting frequency** | How often you report to the donor | "Quarterly" |
| **Description** | Brief project summary | "This programme aims to reduce malnutrition among children under 5..." |

### Step 3: Add team leads (optional)

You can assign:
- **Project Manager** — Overall lead
- **M&E Officer** — Monitoring and evaluation focal person
- **Reporting Officer** — Person responsible for donor reports

These can be changed later.

### Step 4: Save

Click **Create Project**. You will be taken to the project page.

## Project Statuses

Projects move through different statuses:

| Status | Meaning |
|--------|---------|
| **Draft** | Being set up, not yet active |
| **Active** | Implementation is underway |
| **Paused** | Temporarily halted |
| **Completed** | Project end date reached and final report submitted |
| **Archived** | Moved to archive (read-only) |

Only **Active** projects count toward your plan's project limit.

## Project Tabs

Once inside a project, you see a tab bar:

### Overview

A summary dashboard showing:
- Project status and duration
- Days remaining
- Next report deadline
- Readiness score for current reporting period
- Recent activity

### Logframe

Your project hierarchy:
- Goal → Outcomes → Outputs → Activities → Indicators

Build and edit your logframe here. Each item can be expanded to show its children.

### Activities

A log of all activities recorded for this project:
- Filter by date, type, status
- Search by title or description
- Add new activities
- Link activities to outputs

### Evidence

The evidence library for this project:
- All uploaded files and Drive links
- Filter by type, status, date
- Search by content
- Upload new evidence
- Review and verify

### Reports

All reporting periods for this project:
- Create and manage reporting periods
- Track readiness score
- Generate and edit report drafts
- Export reports

### Compliance

The compliance checklist for the active reporting period:
- All open items
- Severity and status
- Assign to team members
- Resolve or accept risks

### Team

All team members on this project:
- See roles and permissions
- Invite new members
- Change roles
- Remove members

### Settings

Project configuration:
- Edit project details
- Change dates, status, budget
- Manage project-specific settings

## Project Dashboard

The Overview tab shows key information at a glance:

**Readiness Score Ring**
A circular indicator showing how complete the current report is (0-100%).

**KPI Stat Cards**
- Active projects
- Reports due
- Indicators on track
- Evidence completeness

**Recent Activity**
A feed of the latest actions in the project.

**Upcoming Deadlines**
Shows when the next report is due and how many days remain.

## Archiving a Project

When a project is completed:

1. Go to **Project → Settings → Change Status**
2. Select **Archived**
3. Confirm

Archived projects are read-only. They remain accessible for reference but cannot be edited. Archiving a project does not free up your plan's project count (only deleting does).

## Deleting a Project

Deleting a project removes it permanently. This cannot be undone.

Before deleting, ensure:
- All reports have been exported
- All data has been backed up
- You have admin permissions

To delete: **Project → Settings → Delete Project** (admin only)

## Project Limits

Your plan limits how many active projects you can have:

| Plan | Active Projects |
|------|----------------|
| Starter | 1 |
| Team | 5 |
| Growth | 20 |
| Enterprise | Unlimited |

You can create additional projects beyond your limit, but you will need to upgrade or archive existing ones to use them fully.
