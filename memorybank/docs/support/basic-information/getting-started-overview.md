# Getting Started with DonorDesk

A complete first-time guide. The whole path takes an afternoon; the [Academy tour](/tour) shows it on a demo project in 10–15 minutes.

## 1. Create your workspace

Sign up at donordesk.online ([details](/support/how-to/create-an-account)). You become the workspace **Admin** on the free **Starter** plan.

## 2. Set up your workspace

Complete the checklist on **Set up your workspace** ([details](/support/how-to/set-up-new-organisation)):

1. **Connect Google Drive** for evidence (required)
2. Organization profile (optional)
3. Default reporting profile (optional)
4. Invite your team (optional)
5. Accept the Terms of Service (required)

## 3. Create a project

Use the three-step wizard: identity, geography and dates, reporting ([details](/support/how-to/create-a-project)).

## 4. Finish project setup

On the project's **Setup** page clear each item:

- **Donor template:** upload the donor's format, review it and approve it ([guide](/support/how-to/upload-donor-template)).
- **Logframe and indicators:** import from Excel or build by hand ([guide](/support/how-to/build-logframe)).
- **Reporting profile:** language, tone and rules.
- **Team:** assign members.

## 5. Collect data during the period

- Log **activities** ([guide](/support/how-to/log-activities)).
- Upload and link **evidence** ([guide](/support/how-to/upload-evidence)).
- Enter and verify **indicator values** ([guide](/support/how-to/update-indicator-values)).

## 6. Create a reporting period

Once the project is Ready ([guide](/support/how-to/create-a-reporting-period)).

## 7. Write the report

Work the four steps: **Update Project → Tell the Story → Generate Draft → Review & Submit** ([AI draft](/support/how-to/generate-ai-report-draft), [editor](/support/how-to/use-the-report-editor)).

## 8. Review, approve, export

Decide on flagged statements, approve sections, clear checks, submit, approve and export ([review](/support/how-to/review-and-approve-reports), [export](/support/how-to/export-reports)).

## Where to get help

Help buttons in the app link to these articles. Email support@donordesk.online for anything else ([contact](/support/contact)).
