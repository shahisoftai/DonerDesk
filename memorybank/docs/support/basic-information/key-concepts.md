# Key Concepts and Terminology

| Term | Meaning in DonorDesk |
|---|---|
| **Workspace / tenant** | Your organisation's private space. Data is isolated from other organisations. |
| **Project** | One funded grant or programme (title, code, donor, country, dates). |
| **Donor template** | The donor's report structure and rules, extracted and approved by you. |
| **Logframe** | The results framework: Goal → Outcome → Output → Activity. |
| **Indicator** | A measurable result with baseline, target, unit and frequency. |
| **Baseline / Target** | Starting value and value to achieve. |
| **Indicator update** | The value for one indicator in one reporting period. |
| **Disaggregation** | A breakdown by sex, age group, disability, location or other. |
| **Reporting period** | One report cycle (for example Q3) with its own data, draft and exports. |
| **Reporting profile** | Language, tone, formatting rules and special requirements for a project's reports. |
| **Activity** | A field update: what happened, where, with how many participants. |
| **Evidence** | A file that proves something: attendance sheets, photos, reports. |
| **Verification** | A person's confirmation that evidence or an indicator value is right. |
| **Confidentiality** | Public, Internal, Sensitive or Highly sensitive label on evidence. |
| **Compliance checklist** | Live list of missing or weak items before a report can go out. Data items close by themselves; confirmations need a person. |
| **Withdrawn activity** | A record left out of reports (duplicate, mistake or replaced). Can be restored. |
| **Archived indicator** | A removed indicator that had values; hidden but its history is kept. |
| **Life of project** | The total since the project started, shown on final, annual and semi-annual reports. |
| **AI Reporter** | The writer that drafts each report section from verified data. |
| **Statement / claim** | A factual sentence in the report that DonorDesk checks against data. |
| **Flagged statement** | A statement the evidence does not support; someone must decide on it. |
| **Draft / version** | Each report save is a version; older versions are kept. |
| **Report gate** | The check that runs before approval and export. |
| **Snapshot** | A sealed copy of the approved report used for donor submission exports. |
| **AI credit** | One successful AI report draft from your monthly plan allowance. |
| **AI Writing Style** | Optional preferences learned from your team's edits (style only). |
| **Academy / demo project** | Guided tour and sample project for learning. |

See the [Report Writing Glossary](/support/report-writing-skills/glossary) for donor-reporting terms.
