# How to Manage Donation Tiers

Donation tiers define the giving levels available to donors, often tied to benefits or recognition. DonorDesk integrates with Creem to manage tier-based giving.

## Setting Up Donation Tiers

1. Go to **Settings > Donation Tiers**
2. Click **Add Tier**
3. Enter the tier name (e.g., "Bronze Supporter")
4. Set the suggested donation amount
5. Add a description of benefits (optional)
6. Set whether the tier is active
7. Save

## Tiers and Creem Integration

If your organisation uses Creem (see 19-Tiers-And-Payments documentation), donation tiers map to Creem products:
1. Each DonorDesk tier corresponds to a Creem product
2. Donor selections sync automatically to Creem
3. Payments are processed through Creem's billing system
4. DonorDesk receives webhook updates on payment status

## Recommended Tier Structure

A common nonprofit tier structure:
- **Supporter** — $10/month — Thank you email
- **Bronze** — $25/month — Supporter benefits + newsletter
- **Silver** — $50/month — All above + annual report
- **Gold** — $100/month — All above + event invite
- **Platinum** — $250/month — All above + name in donor wall

Adjust based on your donor base and organisational capacity.

## Editing Tiers

To edit a tier:
1. Go to **Settings > Donation Tiers**
2. Click the tier name
3. Update the fields
4. Save changes

Note: Changing an amount does not affect existing active recurring donors.

## Deactivating Tiers

To deactivate without deleting:
1. Click the tier
2. Toggle **Active** off
3. Save

Inactive tiers don't appear on new forms but historical records are preserved.

## Tier Reports

Track tier performance:
- Go to **Reports > Donations**
- Filter by tier
- See number of donors per tier, revenue per tier, upgrade/downgrade rates
