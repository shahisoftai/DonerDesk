# How to Review Evidence

> Reviewing evidence means deciding whether a file is accurate and fit to report on. You can verify it, ask for a correction, reject it, archive it, or bring it back for another look.

## Open a file to review

Go to **Evidence**, or to a project's **Evidence** tab, and open the file. The **Verification** panel shows what you can do from its current state.

## Your options

| Option | When to use it | Reason needed? |
|---|---|---|
| **Verify evidence** | The file is accurate and suitable for reporting | No |
| **Ask for a correction** | The file is good, but something must be fixed (for example, a cut-off page) | **Yes** |
| **Reject** | The file is wrong or does not support what it is used for | **Yes** |
| **Archive** | The file is no longer needed, but should be kept on record | No |
| **Bring back for review** | A rejected or archived file needs another look | No |

Write the reason so the person who uploaded the file knows what to fix. They see it on the file as "Reviewer: …".

## Limits

- A file that an approved, exported or submitted report uses cannot be rejected or archived. DonorDesk names the report. Reopen the report first if it has to change.
- Asking for a correction is still allowed for such a file, because it does not take the file out of use.
- If you change the reporting period of a verified file, it goes back to pending review.

## Find files

On **Evidence** you can filter by project, donor, country, verification status, confidentiality, type and where the file was collected. On a project's Evidence tab you can filter by reporting period and where the file was collected. Filters stay in the web address, so you can share a filtered view.

## Good to know

- Every decision is recorded in the audit trail with its reason.
- Sensitive files are shown only to people allowed to open them.
