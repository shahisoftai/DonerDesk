# How to Set a Target Schedule

> A target schedule lets a monthly or quarterly figure be judged against what was due by then, rather than only against the final target.

## When to use it

Use a schedule when the donor expects progress in steps, for example 100 by June and 250 by December, and you want each report to show whether you are on track for that date.

## Add the schedule

1. Open the indicator (**Logframe → select the indicator**) and go to the section that edits its details.
2. Under **Target schedule (optional)**, write one line per date in this form:

   ```
   2026-06-30: 100
   2026-12-31: 250
   ```

3. Select **Save changes** in that section.

Dates must be real days written as YYYY-MM-DD. Each date may appear once. If a line cannot be read, DonorDesk says which line it is and keeps your other changes unsaved until you fix it.

## What you will see

- A period is compared with the latest scheduled target dated on or before its end. Before the first date, the project target applies.
- In the **Data Center**, choose **Variance from scheduled target** to see the difference, for example `-1 (-20%)`.
- A period with no recorded value shows nothing. It is never shown as zero.
- Percentage and ratio indicators do not get a variance.

## Good to know

- A schedule works with cumulative targets. For a count that adds up each month, the schedule is compared with the running total.
- The schedule is part of the framework history, so a change to it is recorded.
