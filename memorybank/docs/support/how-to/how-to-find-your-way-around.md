# How to Find Your Way Around DonorDesk

DonorDesk has had a new layout since Version 4.000 (current version: 4.01). This page shows where things are, and where the things you used to open have gone.

## The screen

- **Left menu** (dark blue): **Home**, **Inbox**, **Projects**, **Dashboards and infographics**, then **Reports** and **Programmes and grants**, then **Team** and **Settings**. You only see what your role may use. **«** at the top left hides it; on a phone **☰** opens it.
- **Top bar**: **Search or jump to…** (press **Ctrl K**, Mac **⌘K**), **Bookmark**, **Academy**, **Language**, the light/dark button, the **bell**, the blue **+ Record** button and your initial (account menu with **Sign out**). On a phone the top bar keeps search, the bell, **+ Record** and your initial; **Language** is on **More**, and the search button also switches light and dark.
- Slide-over panels (Record, an activity's details, a file preview) open from the right (from the bottom on a phone). **Esc** or **×** closes them.

## Search and shortcuts

Press **Ctrl K** to find a project, a file or a page, or to do something: **Create a project**, **Record a value, activity, file or expense**, **Invite a person**, **Go to Inbox**, **Switch light or dark mode**. You only see what your role may do. **?** lists the shortcuts (**G** then **H** goes Home, **G** then **I** the Inbox, **R** opens Record). See [Keyboard shortcuts](/support/reference-keyboard-shortcuts).

## Your work

- **Home** has two tabs: **Home** (what needs you) and **Portfolio**.
- **Inbox** has **To do**, **Team** (for managers) and **Updates**; **Waiting to send** holds what you saved offline.
- **Projects** is the list. Open a project to work inside it.

## Inside a project

A project has seven tabs. Under the tabs a second row shows the pages inside; rarely used ones are under **More**.

| Tab | What is in it |
|---|---|
| **Overview** | Summary and what needs you. **More**: Management report, Changes of plan, People reached, Ask DonorDesk |
| **Plan** | **Results framework**, **Work plan**, **Where we work** |
| **Data** | **Data Center**, **Enter data**, **Import**, **Forms**, **Datasets**; **More**: Data tables, Charts, Maps |
| **Evidence** | The project's files |
| **Reports** | **Reports**, **Donor templates**, **Compliance**; **More**: Infographics |
| **Finance** | The finance register |
| **Settings** | **Project settings**, **Team**, **Setup** |

A report has its own four-stage bar: **Inputs → Story → Draft → Review and export**, with one button for the next step.

## Reports, evidence and files for every project

**Reports** in the left menu has four tabs: **Reports**, **Evidence**, **Compliance** and **Download Center**, each across all your projects.

## Visuals

**Dashboards and infographics** has **Designs**, **Templates** and **Datasets** and a **Tools ▾** menu: **Chart Studio**, **Maps**, **Images and brand**, **Data alerts** and **TV display**.

## Settings

**Settings** has a list on the left: **General**, **Workspace setup**, **Places**, **Finance**; **Starting answers**, **Sector library**, **Donor requirements**; **AI features**, **AI usage**, **Writing style**; **Sign-in and two-step**, **Audit log**; **Plan and billing**; **API keys and webhooks**.

## Where did it go?

| Before | Now |
|---|---|
| My Work | **Inbox → To do** (and **Team**) |
| Notifications | **Inbox → Updates** |
| Portfolio (menu) | **Home → Portfolio** tab |
| Evidence, Compliance, Download Center (menu) | Tabs under **Reports** |
| Project tab **Reporting** | **Reports** tab |
| Project tab **Logframe** | **Plan → Results framework** |
| Project tab **Activities** | **Plan → Work plan** (and **Completed activities**) |
| Project tab **Team** | **Settings → Team** |
| Project tab **Settings**, **Setup** | **Settings → Project settings**, **Settings → Setup** |
| Project **Templates** | **Reports → Donor templates** |
| **Collection forms** | **Data → Forms** |
| **Report builder** | **Data → More → Data tables** |
| Settings tab **Setup** | **Settings → Workspace setup** (the **Get started** checklist) |
| Settings tab **Security** | **Settings → Sign-in and two-step** |
| Settings tab **AI Writing Style** | **Settings → Writing style** |
| The one-page new-project form | The project wizard (**New project**) |
| The classic report workspace | Retired: one report editor with a four-stage bar |

See [How to use Home and the Inbox](/support/how-to/use-the-dashboard), [Understanding projects](/support/getting-started/understanding-projects) and [How to personalise your workspace](/support/how-to/personalise-your-workspace).
