# How to Use Bulk Actions

Bulk actions let you apply changes to multiple records simultaneously, saving time when managing large donor lists.

## Selecting Records

In any list view (Donors, Donations, etc.):
- Click the checkbox next to each record to select individually
- Click the header checkbox to select all visible records
- Use **Select All on Page** for all records matching current filters

## Available Bulk Actions

### For Donors

- **Add Tag** — apply a tag to all selected
- **Remove Tag** — remove a tag from all selected
- **Export** — export selected records
- **Merge** — combine duplicate donor records
- **Delete** — remove selected donors (admin only)

### For Donations

- **Export** — export selected donations
- **Add Note** — add a note to all selected
- **Mark as Reviewed** — mark selected donations as reviewed
- **Send Receipt** — resend receipts to selected donors

### For Campaigns

- **Activate** — turn on selected campaigns
- **Deactivate** — turn off selected campaigns
- **Archive** — archive selected campaigns

## Performing a Bulk Action

1. Select the records using checkboxes
2. The **Bulk Actions** button becomes active in the top toolbar
3. Click **Bulk Actions**
4. Select the action from the dropdown
5. Confirm any required details (e.g., which tag to add)
6. Click **Apply**

A progress indicator shows the operation status. Large bulk operations may take a moment to process.

## Bulk Import

To import multiple records at once:
1. Go to **Settings > Imports**
2. Click **New Import**
3. Download the CSV template
4. Fill in the data
5. Upload the completed CSV
6. Map columns to DonorDesk fields
7. Review and confirm import

## Bulk Operations and Audit Trail

All bulk actions are logged in the audit trail with:
- Who performed the action
- What was changed
- When it occurred
- Which records were affected

For help with bulk actions, contact support@donordesk.online.
