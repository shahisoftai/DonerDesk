# How to Upload Evidence

Evidence is the proof that your project activities happened. Uploading evidence to DonorDesk makes it organised, searchable, and ready for your donor reports.

## What You Need

- A project that is set up
- The evidence files ready on your device or Google Drive
- Files in supported formats: PDF, DOCX, DOC, XLSX, CSV, JPG, PNG, TXT

## Method 1: Upload from Your Computer

### Step 1: Go to Evidence

1. Open your project
2. Click the **Evidence** tab

### Step 2: Start the Upload

Click **Upload Evidence** at the top right.

### Step 3: Select Your File

1. Click **Select File**
2. Browse to your file
3. Select it
4. Wait for it to upload

You can upload multiple files at once by selecting several.

### Step 4: Fill in the Metadata

Fill in the details about this evidence:

| Field | What to enter | Required? |
|-------|--------------|-----------|
| **Title** | Short descriptive name | Yes |
| **Evidence type** | What kind of file it is | Yes |
| **Related activity** | Which activity it proves | Recommended |
| **Related output/indicator** | Link to specific outputs/indicators | Optional |
| **Location** | Where the activity took place | Recommended |
| **Date of activity** | When the activity happened | Recommended |
| **Confidentiality level** | Public, Internal, Sensitive, Highly Sensitive | Yes |
| **Notes** | Any additional information | Optional |

### Step 5: Confirm

Click **Save Evidence**.

The file will appear in your Evidence Library with status **Uploaded**.

## Method 2: Link from Google Drive

If you store files in Google Drive:

### Step 1: Connect Your Google Drive First

1. Go to **Settings → Storage**
2. Click **Connect Google Drive**
3. Authorise DonorDesk to access your Google Drive

### Step 2: Link an Evidence File

1. Go to **Evidence** tab
2. Click **Link from Drive**
3. Browse your Google Drive
4. Select the file
5. Fill in the metadata (same as above)
6. Click **Link**

This creates a reference to your Drive file — no extra storage space is used in DonorDesk.

## Confidentiality Levels

Choose carefully — this affects who can see the file and whether it appears in exports:

| Level | When to use |
|-------|------------|
| **Public** | Can be shared openly with anyone |
| **Internal** | Organisation use only, not for beneficiaries |
| **Sensitive** | Contains personal data — restrict access |
| **Highly Sensitive** | Contains very personal or protected data |

## What Happens After Upload

1. **AI processes the file** — Within a moment, AI analyses the content and suggests tags
2. **Tags appear** — Review the suggested tags in the **Tags** column
3. **Verification needed** — A reviewer (M&E Officer, Compliance Officer) must verify the evidence

## Reviewing AI Tags

After upload, check the suggested tags:

1. Click on the evidence item
2. Look at the **Tags** section
3. Accept tags that are correct (click the checkmark)
4. Remove tags that are wrong (click the X)
5. Add any missing tags

## Verifying Evidence

Evidence needs to be verified by a human before it can be used in reports:

1. Click on the evidence item
2. Review the file and metadata
3. If correct, click **Verify** at the top
4. If it has issues, click **Needs Correction** and add a note explaining what to fix

Verified evidence shows a green checkmark.

## Linking Evidence to Activities

When you log an activity, you can attach evidence at the same time:

1. When logging an activity, scroll to **Attach Evidence**
2. Upload or link the file
3. The evidence will automatically link to that activity

Or link evidence after the fact:
1. Upload the evidence
2. Open the evidence item
3. In the **Related activity** field, select the activity
4. Save

## Searching and Filtering Evidence

The Evidence Library has powerful tools to find files:

**Search:** Type in the search bar to search by filename, title, notes, or extracted text content.

**Filter by:**
- Evidence type
- Verification status
- Date range
- Uploaded by
- Confidentiality level
- Related activity

## Deleting Evidence

To remove evidence:
1. Click on the evidence item
2. Click **Delete** (trash icon)
3. Confirm

**Note:** Deleting evidence removes it from the library and any linked activities. If you have already exported reports citing this evidence, those exports are not automatically updated.
