# How to Manage Recurring Donations

Recurring donations are a powerful way to build sustainable funding for your organisation. DonorDesk makes it easy to set up, manage, and track recurring donor commitments.

## Setting Up Recurring Donations

When a donor selects a recurring option at checkout, DonorDesk automatically creates a scheduled donation record linked to their profile. You can view all active recurring donations in the **Donations** section, filtered by type.

## Monitoring Recurring Donations

The Recurring Donations dashboard shows:
- Active recurring commitments
- Next expected payment date
- Historical completion rate
- Donor lifetime value from recurring sources

## Handling Failed Recurring Payments

When a scheduled payment fails:
1. DonorDesk automatically retries based on your retry policy
2. The donor receives an email notification with an update link
3. You can manually process an update card on file
4. Failed attempts are logged in the audit trail

## Cancelling a Recurring Donation

To cancel a recurring donation:
1. Go to the donor's profile
2. Click on the active recurring donation
3. Select **Cancel Recurring Commitment**
4. Choose a reason from the dropdown
5. Confirm the cancellation

The donor will receive an automatic confirmation email.

## Pause or Modify Recurring Donations

You can pause a recurring donation for up to 3 months without losing the donor's commitment. To modify the amount or frequency, you must cancel the existing commitment and create a new one with the updated terms.

## Reporting

Use the Recurring Donations report to track:
- Monthly recurring revenue (MRR)
- Churn rate
- Average recurring donation value
- Upgrade/downgrade trends

For help with recurring donations, contact support@donordesk.online.
