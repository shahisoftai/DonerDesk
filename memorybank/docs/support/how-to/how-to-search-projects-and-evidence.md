# How to Search for Projects and Evidence

DonorDesk has a powerful search function that helps you find projects, evidence, activities, and reports quickly.

## Searching Across DonorDesk

### Global Search

1. Press **Ctrl + K** (or **Cmd + K** on Mac)
2. A search dialog opens
3. Type your search term
4. Results appear as you type
5. Click a result to go directly to it

### Search by Project

**Within the Projects page:**
1. Go to **Projects**
2. Click the search bar
3. Type the project name, code, donor, or country
4. Results filter automatically

### Search by Evidence

**In the Evidence Library:**
1. Go to your project → **Evidence**
2. Click the search bar
3. Search by:
   - File name
   - Evidence title
   - Notes
   - Extracted text content (DonorDesk reads inside documents)
   - Tags

### Search by Activity

**In the Activities section:**
1. Go to your project → **Activities**
2. Use the search bar
3. Search by activity title, description, or location

## Filtering Results

Search is powerful on its own, but filters help narrow down results:

### Evidence Filters

| Filter | Use to find |
|--------|------------|
| **Evidence type** | Photos, attendance sheets, reports, etc. |
| **Verification status** | Uploaded, Verified, Needs Correction |
| **Date range** | Uploaded in a specific period |
| **Confidentiality** | Public, Internal, Sensitive |
| **Uploaded by** | Who uploaded the file |
| **Related activity** | Evidence linked to a specific activity |

### Project Filters

| Filter | Use to find |
|--------|------------|
| **Status** | Active, Draft, Paused, Completed, Archived |
| **Donor** | Projects from a specific donor |
| **Sector** | Projects in a specific sector |
| **Country** | Projects in a specific country |

## Tips for Better Search

### Be Specific

**Instead of:** "training"
**Try:** "training on ANC screening protocols August 2026"

### Use Filters Together

Combine filters to narrow results:
1. Filter by evidence type = "Attendance sheet"
2. Filter by date = "Last 30 days"
3. Filter by status = "Verified"

### Search Extracted Text

DonorDesk reads the content inside documents. You can search for:
- Specific names mentioned in reports
- Topics discussed in meeting minutes
- Numbers in spreadsheets

## Search Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl + K` | Open global search |
| `Ctrl + F` | Search within current page |
| `Esc` | Close search dialog |

## What Cannot Be Searched

Currently, these cannot be searched:
- Individual report section content (search the report title instead)
- Deleted items
- Archived projects (unless you are in the archived view)

## Finding Evidence by Content

DonorDesk uses AI to extract text from uploaded documents. This means you can search for something mentioned inside a file, not just the filename.

**Example:**
You upload a 50-page report. Later, you can search for "malnutrition treatment protocol" and DonorDesk will find that report even though the filename does not contain those words.

## Saving Searches

Some users find it helpful to:
- Bookmark filtered views in your browser
- Use the same filter combinations regularly
- Download filtered lists for offline reference
