# How to Search and Filter Projects and Evidence

DonorDesk has search and filters where you work most. There is no single search box that searches everything yet.

## Projects

1. Click **Projects** in the main menu, or press **Ctrl/Cmd + K** to jump to project search.
2. Type in the search box (title, code, donor or country).
3. Narrow with the **status** and **sector** filters and change the sort (for example **Soonest deadline**).

Filters are kept in the page address, so you can bookmark or share a filtered view.

## Evidence

On **Evidence** (all projects) or a project's Evidence tab use the filter bar:

- Search by **file name or title**
- **Verification** status (Uploaded, AI tagged, Pending review, Verified, Needs correction, Rejected, Archived)
- **Confidentiality** (Public, Internal, Sensitive, Highly sensitive)
- Reporting period

## Other lists

- **My Work** filters by type and due date.
- **Audit log** filters by actor, event and entity ([guide](/support/how-to/use-the-audit-trail)).
- **Team** search by name or email and filter by role.
- **Notifications** filter All, Unread or Read.
