# How to Export Donor Data

DonorDesk provides flexible export options so you can work with your data in external tools, share reports with stakeholders, or maintain backups.

## Exporting the Donor List

1. Navigate to **Donors**
2. Apply any filters to narrow the list
3. Click the **Export** button in the top right
4. Select your format: CSV, Excel, or PDF
5. Choose which fields to include
6. Click **Download**

Exports are generated in real-time and reflect the current filtered state.

## Exporting Donation History

1. Navigate to **Donations**
2. Set your date range and filters
3. Click **Export**
4. Select the format
5. Choose columns (donor info, amount, date, campaign, payment method, etc.)
6. Download your file

## Scheduled Exports

For recurring reporting needs:
1. Go to **Settings > Integrations > Exports**
2. Click **New Scheduled Export**
3. Define the query (filters, date range, columns)
4. Set the frequency (daily, weekly, monthly)
5. Choose delivery method (email or webhook)
6. Save the schedule

Scheduled exports are sent automatically to the designated email address.

## Exporting Audit Logs

Audit logs can be exported for compliance purposes:
1. Go to **Settings > Audit & Compliance**
2. Click **Export Audit Log**
3. Set the date range
4. Choose CSV or JSON format
5. Download the file

## Data字段 Reference

When exporting, you can include fields such as:
- Donor name, email, phone
- Address and billing information
- Total donated, donation count, average gift
- First and last donation dates
- Tags and notes
- Associated campaigns

For complex export needs, contact support@donordesk.online.
