# How to Use the Search Functionality

DonorDesk provides powerful search capabilities to quickly find donors, donations, and records across your entire database.

## Global Search

Press `/` anywhere in the app to open the global search bar. Type to search across:
- Donor names and emails
- Donation amounts and references
- Campaign names
- Notes and tags
- Transaction IDs

## Donor Search

The **Donors** page has a dedicated search bar. Search by:
- Full name
- Email address
- Phone number
- Donor ID
- Any tag

Results appear as you type, sorted by relevance.

## Advanced Search Operators

Use operators for precise searches:
- `"exact phrase"` — find exact name match
- `email:john@example.com` — search by email
- `amount:>100` — donations over 100
- `amount:50-100` — donations between 50 and 100
- `date:>2024-01-01` — donations after a date
- `tag:major-donor` — donors with specific tag

## Search Filters

Combine search with filters:
1. Type your search term
2. Open the filter panel on the right
3. Set additional criteria (date range, amount, campaign, etc.)
4. Results update instantly

## Saving Searches

Save frequently used searches:
1. Enter your search criteria
2. Click **Save Search** above results
3. Name the search (e.g., "Monthly donors over 500")
4. Access saved searches from the sidebar

## Recent Searches

Your 10 most recent searches are saved automatically and shown when you open the search bar. Click any to re-run.

## Search Performance

For large databases (50,000+ donors), search may take a few seconds. For optimal performance, use specific search terms rather than broad queries.

For help with search, contact support@donordesk.online.
