# How to Import Your Plan

If your plan is already in a spreadsheet, you can bring it in instead of typing it. Open **Activities** and select **Import a sheet**.

## Bring it in

You can upload an Excel or CSV file, paste the rows, or dictate them. You can edit the text before you create anything.

## The columns

The first row names the columns. **Title** and **Start** are required.

| Column | What to put |
|---|---|
| Logframe Code | The code of the output or activity in your logframe (optional) |
| Title | What is planned |
| Start | A date such as 2026-03-10 |
| End | A date; leave empty for a one-day activity |
| Lead email | The email of an active member of this project |
| Location | Where |
| Sessions | A whole number of 1 or more |
| Repeats | No, Weekly or Monthly (repeats run to the end of the project) |

## If a row has a problem

Nothing is imported. The message names every row to fix ("Row 3: end is before the start"), so you can correct the text and try again. A row that is already planned for the same dates is skipped, so importing the same file twice does not create duplicates.

## Copy a plan from another project

When you copy another project's setup into an empty project, you can tick **Also copy the planned activities**. Dates move with the new project's start; leads and progress are not copied.
