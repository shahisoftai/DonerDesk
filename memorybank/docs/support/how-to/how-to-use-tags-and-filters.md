# How to Use Tags and Filters

Tags and filters help you organise donors and donations, making it easy to find specific records and generate targeted reports.

## Understanding Tags

Tags are custom labels you can apply to donors and donations. Examples include:
- "Major Donor" — for donors above a certain threshold
- "Monthly Giver" — for recurring donors
- "Event Attendee 2025" — for event-specific tracking
- "Corporate Partner" — for business donors
- "Lapsed" — for donors who haven't given in 12+ months

## Adding Tags to Donors

1. Open a donor profile
2. Scroll to the **Tags** section
3. Click **Add Tag**
4. Select from existing tags or create a new one
5. Tags are saved automatically

## Bulk Tagging

To apply tags to multiple donors at once:
1. Go to the **Donors** list view
2. Check the boxes next to donor names
3. Click the **Bulk Actions** button
4. Select **Add Tag** or **Remove Tag**
5. Choose the tag and confirm

## Using Filters

Filters allow you to narrow down lists without modifying data. The filter panel is available on the Donors, Donations, and Events pages.

### Available Filter Options

- **Date range** — filter by creation date, donation date, etc.
- **Amount range** — filter by donation amount
- **Payment method** — filter by credit card, bank transfer, etc.
- **Campaign** — filter by associated campaign
- **Tags** — filter by applied tags
- **Status** — filter by active, cancelled, refunded, etc.

### Saving Filter Views

Once you've configured a filter set:
1. Click **Save Current View**
2. Name the view (e.g., "Major Donors 2025")
3. The view appears in your sidebar for quick access

## Filter-Based Reports

Use saved filter views to generate reports specific to your criteria. Reports respect the same filters and can be exported to CSV or PDF.
