# How to Use the Report Editor

The report editor is where you read, edit, check and approve the report. It works like a normal document, with checks alongside.

Open it from **Projects → project → Reporting →** the reporting period.

## Layout

| Area | What it does |
|---|---|
| **Top bar** | Period and project, status (Draft / Under review …), version and "All changes saved", the readiness pill (**72% ready · 3 to do**) with previous/next arrows, the **⋯** menu, and the **one primary button**. |
| **Outline** (left) | The report's sections with numbering and a progress count (for example 2/7 approved). **+ Add** a section, **Reorder** them, and open **Report inputs**. |
| **Document** (centre) | One continuous document. Click into a section to edit it. |
| **Inspector** (right) | Details for the selected section: **Statements**, **Sources**, **Chart**, **Comments**, **History**. |

## The primary button

It always shows the next thing to do: *Generate report → Review n flagged statements → Approve n remaining sections → Finish n remaining checks → Submit for review → Approve report → Export report.* Just follow it.

## Editing text

- Click into a section and type. The toolbar has headings, bold, italic, lists, quotes, tables, code and links.
- Changes save automatically; the top bar confirms. Every save creates a version.
- Paste from Word or the web: formatting is cleaned to the set that all exports support.
- **Ask AI** (✦) on a selection: **Rewrite**, **Shorten**, **Expand**, or **Make donor-friendly**. You see the suggested text and choose whether to accept. It never adds numbers.
- **↻ Regenerate** rewrites a whole section (optionally with your instruction). If the AI cannot produce a valid version, your existing text is kept.

## Checking statements

Statements in the text that make factual claims are highlighted. In the **Statements** tab, each is **Matches evidence**, **Needs a decision**, **Kept with a note**, **Left out** or **Not checked (minor)**. Use the number-fix button to apply the verified value, edit the text, keep it with a reason, or leave it out.

## Sources, charts and history

- **Sources** lists the evidence files, activities and indicator updates behind the section; click to open them.
- **Chart** lets you add a bar, line, pie, area, radar or gauge chart to a section. Exports show the same chart.
- **History** shows each version: written by the AI, edited by a person, regenerated, rewritten with AI, number corrected from evidence, or restored. You can restore an earlier version.

## The ⋯ menu

Regenerate the whole draft, **Edit data & story** (the inputs page), **Scan for missing items**, **Version history**, **Export center** and **Keyboard shortcuts**. Items you have no permission for are hidden.

## When inputs change

If you change indicator values, evidence or the story after generating, an **Inputs changed** banner appears. Re-check the affected sections, or regenerate them if you want new text. A summary section is flagged if other sections changed a lot after it was written.

## Keyboard shortcuts

**j / k** next or previous section, **n / Shift+N** next or previous issue, **e** edit, **a** approve, **?** help. See [Keyboard shortcuts](/support/reference-keyboard-shortcuts).

## Older workspace

Some workspaces may still show the previous, more crowded report workspace. The steps are the same; the buttons are laid out differently.
