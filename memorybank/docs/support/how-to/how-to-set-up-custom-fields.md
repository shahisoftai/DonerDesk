# How to Set Up Custom Fields

Custom fields let you capture additional donor and donation information beyond the standard fields, tailored to your organisation's specific needs.

## Accessing Custom Fields

Go to **Settings > Donor Fields** to manage donor custom fields.
Go to **Settings > Donation Fields** to manage donation custom fields.

## Creating a Donor Custom Field

1. Click **Add Custom Field**
2. Enter the field name (e.g., "Preferred Contact Method")
3. Select the field type:
   - **Text** — free-form text
   - **Number** — numeric values
   - **Date** — calendar date
   - **Dropdown** — predefined options
   - **Checkbox** — yes/no
   - **Multi-select** — multiple selections
4. If dropdown or multi-select, add the options
5. Toggle whether the field is required
6. Save the field

## Creating a Donation Custom Field

Same steps as donor fields, but via **Settings > Donation Fields**. Donation fields appear on donation records and can be set during the donation process or added manually.

## Using Custom Fields in Forms

Custom fields can be displayed on public donation forms:
1. Go to **Settings > Donation Forms**
2. Edit the form
3. Click **Add Field**
4. Select your custom field
5. Arrange the order
6. Save the form

## Filtering and Searching by Custom Fields

After custom fields are populated:
1. Go to the **Donors** or **Donations** list
2. Open the filter panel
3. Find your custom field under "Custom Fields"
4. Set the filter criteria
5. Results update in real-time

## Custom Fields in Reports

Include custom fields in exports and reports:
1. When generating a report, expand the "Columns" section
2. Find the custom field section
3. Check the fields to include
4. Generate the report

## Editing and Deleting Custom Fields

To edit: click the field name in Settings and modify.
To delete: click the delete icon. Warning — deleting removes all stored values permanently.

For help with custom fields, contact support@donordesk.online.
