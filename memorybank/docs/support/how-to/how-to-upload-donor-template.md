# How to Upload a Donor Template

A donor template is the report format that your donor requires. When you upload it, DonorDesk reads its structure and creates the report sections automatically.

## What You Need

- Your donor's report template file
- Accepted formats: **PDF, DOCX, DOC**
- The project you want to attach the template to

## Step-by-Step

### Step 1: Go to the Templates Section

1. Open your project
2. Click the **Templates** tab

### Step 2: Upload the Template

1. Click **Upload Template**
2. Select your template file from your computer
3. Wait for the file to upload

### Step 3: Review the Extracted Sections

DonorDesk reads the template and extracts the sections. You will see a preview:

```
✓ Executive Summary
✓ Project Overview
✓ Activities Completed
✓ Indicator Progress
✓ Challenges and Mitigation
✓ Lessons Learned
✓ Financial Summary
✓ Annex A — Attendance
✓ Annex B — Photos
```

Review each section. You can:
- Accept the section as extracted
- Rename the section (click the name to edit)
- Delete a section you do not need
- Reorder sections (drag and drop)

### Step 4: Link to Requirements

For each section, you can optionally link to:
- A specific donor requirement
- A compliance checklist item
- A logframe element

This helps DonorDesk know what belongs in each section.

### Step 5: Confirm

Click **Save Template** when you are done.

## What Happens After Upload

When you create a reporting period and link this template:
- The reporting period will have the same sections
- Sections will appear in your report draft
- The compliance checklist will check for the required annexes

## Creating a Template Without a File

If you do not have a donor template file:

1. Go to **Templates** tab
2. Click **Create Template Manually**
3. Click **Add Section**
4. Enter the section name
5. Repeat for each section you need
6. Click **Save**

You can always add or remove sections later.

## Editing an Existing Template

To change a template after uploading:

1. Go to **Templates** tab
2. Click on the template
3. Make your changes
4. Click **Save**

**Note:** Changing a template does not affect existing reporting periods. It only affects new ones you create after saving.

## Template Example

A typical donor report template might include:

```
1. Executive Summary
2. Project Progress
   2.1 Activities Completed
   2.2 Indicator Achievement
3. Evidence of Results
4. Challenges and How They Were Addressed
5. Lessons Learned
6. Plan for Next Period
Annex A: Activity Attendance Sheets
Annex B: Photos
Annex C: Indicator Data Table
```

## Tips

- Upload the template **before** you create your first reporting period for best results
- If your donor has a specific format, upload their actual template — DonorDesk will read it
- You can have **multiple templates** for different donors or report types
- Link sections to donor requirements to get better AI draft quality
