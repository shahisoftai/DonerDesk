# How to Set Up Automated Receipts

Automated receipts save your team time and provide donors with instant confirmation of their contributions.

## Default Receipt Settings

When enabled, DonorDesk automatically sends a receipt email every time a donation is successfully processed. Go to **Settings > Email > Automated Receipts** to configure.

## Enabling Automated Receipts

1. Go to **Settings > Email > Automated Receipts**
2. Toggle **Send automated receipts**
3. Select which email address to send from (must be verified)
4. Choose the receipt template to use
5. Save

## Customising the Receipt Template

1. Go to **Settings > Email Templates**
2. Click on the active receipt template
3. Edit the subject line and body
4. Use merge tags to personalise:
   - `{{donor_name}}` — donor's full name
   - `{{amount}}` — donation amount
   - `{{date}}` — donation date
   - `{{campaign}}` — campaign name (if applicable)
   - `{{transaction_id}}` — internal reference
5. Preview with sample data
6. Save

## Donor Opt-Out

Some donors may not want receipts. You can:
- Manually disable receipts for a specific donor in their profile
- Include an unsubscribe link in the receipt (recommended for compliance)

## Annual Receipt Summaries

Send annual summary receipts for tax purposes:
1. Go to **Settings > Email > Annual Summaries**
2. Toggle **Send annual summaries**
3. Set the send date (typically January of the following year)
4. Customise the template
5. Save

Annual summaries include total donated for the year and are sent to all donors with at least one donation in that tax year.

## Manual Receipt Resend

To manually resend a receipt:
1. Open the donation record
2. Click the **...** menu
3. Select **Resend Receipt**
4. Confirm

For help with automated receipts, contact support@donordesk.online.
