# Troubleshooting Dashboard and Loading Issues

## Dashboard Shows "Loading..." Forever

### Step 1: Refresh the Page

Press F5 or Ctrl+R (or Cmd+R on Mac) to refresh.

### Step 2: Check Your Internet Connection

Try loading another website to confirm your connection is working.

### Step 3: Try a Different Browser

If refresh does not work, try Chrome, Firefox, Edge, or Safari.

### Step 4: Clear Browser Cache

1. Open browser settings
2. Clear cache and cookies for donordesk.online
3. Log in again

### Step 5: Check Server Status

Visit **https://donordesk.online** to see if the service is up. If the site itself is down, this is a known outage — wait and try again.

## Data on Dashboard Is Outdated

Dashboard data refreshes:
- When you load the page
- When you navigate between sections
- When you submit or update data

**To force a refresh:**
1. Navigate away from the dashboard
2. Come back to it
3. The data will reload

## Specific Widgets Are Missing

### Missing KPI cards

Some cards may not show if there is no data for them yet (e.g., no reports if you have not created any projects).

**To show all cards:**
- Make sure you have created at least one project
- Make sure you have created at least one reporting period

### Missing charts

Charts appear after you have indicator data across at least 2 reporting periods (for comparison).

## Readiness Score Shows Wrong Percentage

The readiness score is calculated from:
- Section completion (25%)
- Indicator updates (20%)
- Evidence completeness (25%)
- Compliance checklist (20%)
- Approval status (10%)

If the score seems wrong:
1. Check each component individually
2. Verify all indicator values are submitted and verified
3. Check the compliance checklist for unresolved items
4. Make sure all report sections are marked as reviewed

## Cannot See All My Projects on the Dashboard

- **Free/Starter plan:** Only 1 project shows on the main dashboard. Go to **Projects** to see all.
- **Team/Growth:** All projects should appear. If not, you may not have access — ask your admin.
- **Filtering:** Make sure filters are set to "All" projects, not a specific one.

## Notifications Not Appearing

1. Check your notification settings in **Settings → Notifications**
2. Make sure notifications are enabled for the events you care about
3. Check that your email is verified (some notifications require it)

## Activity Feed Is Empty

The activity feed shows recent actions by team members. If it is empty:
- No actions have been taken yet
- Actions by other users may not appear if you have limited permissions
- The activity feed only shows actions from the last 30 days

## Charts Are Not Displaying

1. Make sure you have at least 2 reporting periods with data
2. Charts need indicator data to display
3. Check that the indicator type supports charts (number and percentage types work best)

## Theme/Display Issues

### Dark/Light mode not switching

1. Click the sun/moon icon in the top right
2. If it does not work, clear browser cache and try again
3. Make sure JavaScript is enabled

### Page looks broken or misaligned

1. Try a different browser
2. Clear browser cache
3. Zoom level may be too high — press Ctrl+0 to reset to 100%
4. Disable browser extensions temporarily
