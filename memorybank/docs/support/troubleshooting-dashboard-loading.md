# Troubleshooting Dashboard and Home Loading

## Home shows "Could not load" cards

Individual cards can fail without breaking the page (for example **Notifications unavailable**, **Deadlines unavailable**, **Projects unavailable**). Reload after a minute. If one stays broken, email support@donordesk.online with the card name and time.

## Home is empty

- No projects yet: use **Create your first project** (Admin) or ask an Admin to assign you.
- No deadlines: create reporting periods with donor deadlines.
- "No urgent work items right now" means nothing needs your attention.

## Numbers differ from a project's page

Readiness and counts on Home are summaries across projects you can see. Open the project for the authoritative status.

## My Work shows nothing

The list only includes items you can act on. Clear the type and urgency filters.

## Notifications missing

Notifications appear only inside DonorDesk (email is not active). Use the bell, **Notifications**, and My Work.

## Slow loading

See [Troubleshooting browser performance](/support/troubleshooting/browser-performance).
