# Daily Summary and Reminders

Each morning at 07:00 (your organisation's time zone, set under **Settings**), everyone with open work gets **one** summary: what is late and what is due today and this week. Nothing is sent on a quiet day.

When an item has been late for 7 days, its owner and the project manager get one extra note. It is not repeated.

## Your setting

Open **Notifications** and choose how you want email: always, only for urgent or late items, or never. The note in the bell always arrives.

## For administrators

The summary is sent by an hourly job that acts in each organisation's own morning. If nobody receives anything, check the organisation's time zone and each person's email setting.
