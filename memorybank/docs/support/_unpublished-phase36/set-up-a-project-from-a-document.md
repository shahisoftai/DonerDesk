# Set up a project from a document

*Draft. Do not publish or register until the feature has been checked in a browser and its quality measured (Phase 36 plan §10).*

If you already have a proposal, concept note or logframe, DonorDesk can read it and suggest the setup. You review the suggestions before anything is created.

## Turn it on (administrators)
Settings → "Set up projects from a document". The document is sent to the AI service with personal details such as names, e-mail addresses and phone numbers removed first.

## Where your document goes
Your document is saved in your own Google Drive, in the DonorDesk folder, not on DonorDesk's servers. When your project is created, it moves into that project's folder under 00-Project-Documents. Google Drive must be connected in Settings first.

## Use it
1. Projects → New project → "Set up from a project document".
2. Add up to five files about the same project, or paste text, then wait while they are read.
3. Go through each area (project facts, results, indicators, reporting periods, activities, places, funding, risks). Each suggestion shows the words it came from. Accept what is right, reject what is not. For a project fact you can write your own version.
4. Anything the document does not say shows as **Not stated**. DonorDesk never fills a gap with a guess.
5. Check the project details, then **Create the project**. If something could not be created, the rest stays and you can finish it after fixing the problem.

## What is not created
Indicator values, evidence, activity records and people. Budget lines are read but you add them on the Finance page, next to the activity they belong to.
