# Understanding Indicators and Targets

An **indicator** is how you measure a result. A **target** is the value you plan to reach.

## Fields

| Field | Notes |
|---|---|
| Name and code | Short, stable codes (OUT-1) are used for imports. |
| Type | Number, Percentage, Yes/No, Text, Ratio, Currency or Custom. |
| Logframe item | The goal, outcome, output or activity it measures. |
| **Baseline** | The starting value. |
| **Target** | The value to reach by the end. |
| Unit | For example people, %, USD. |
| Frequency | How often it is measured. |
| Data source / Means of verification | Optional; where the figure comes from and how it is proven. |
| Disaggregation | Optional breakdown by sex, age group, disability, location or other. |

Baseline, target, unit and frequency are required for quantitative indicators before a project is reporting-ready.

## Period values

For each reporting period you enter the **period achievement** in the indicator grid. See [How to update indicator values](/support/how-to/update-indicator-values).

## How values are combined

Set the indicator's **reporting basis**: latest value, sum of period values, average, highest, lowest or cumulative to date. Percentages and ratios use a **numerator ÷ denominator** calculation from two other indicators. Set **direction of progress** (higher is better, lower is better, neutral).

## Progress

The indicator page shows **progress toward target** (share of the distance from baseline to target), the latest period breakdown and the update history.

## Verification

Each update is Draft → Submitted → **Verified** (or Needs correction / Rejected). Reports use verified values and mark unverified ones.

## Good practice

- Set baselines and targets from the donor's agreement.
- Enter values every period and link evidence.
- Keep indicator names identical to the donor's wording.
