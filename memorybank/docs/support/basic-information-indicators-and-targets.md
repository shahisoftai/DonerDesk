# Understanding Indicators and Targets

Indicators are how you measure whether your project is achieving its goals. This guide explains how to set up and use indicators effectively.

## What Is an Indicator?

An indicator is a measurement that tells you:
- Where you are starting from (baseline)
- What you aim to achieve (target)
- How you are progressing (current value)

## Indicator vs Indicator Update

| Term | Meaning |
|------|---------|
| **Indicator definition** | The permanent record: name, unit, target |
| **Indicator update** | The value for a specific reporting period |

Example:
- **Indicator:** "Number of women receiving 4+ ANC visits" — unit: women, target: 400
- **Update for Q1:** value: 45
- **Update for Q2:** value: 120 (cumulative)

## Parts of an Indicator

### Code
A short identifier: `OUT-1`, `IND-NUT-02`

### Name
Clear description of what is measured: "Number of women receiving 4+ ANC visits"

### Type

| Type | When to use | Example |
|------|------------|---------|
| **Number** | Counting discrete items | 50 children trained |
| **Percentage** | Proportions or rates | 75% institutional delivery |
| **Yes/No** | Binary outcomes | Community committee formed: Yes |
| **Text** | Descriptive updates | Quality rating: Good |
| **Ratio** | Comparing two values | Boy:girl ratio 1:3 |
| **Currency** | Financial amounts | USD 45,000 disbursed |

### Baseline
The starting value before the project began. Usually 0, but can be an existing figure.

### Target
What you aim to achieve by the end of the project.

### Unit
What you are counting: women, children, sessions, %, etc.

## Setting Good Targets

### SMART Targets

| Letter | What it means | Example |
|--------|--------------|---------|
| **S** — Specific | Clearly defined | "400 women" not "many women" |
| **M** — Measurable | Can be counted | Yes for number, harder for % |
| **A** — Achievable | Realistic given resources | 400 vs 400,000 |
| **R** — Relevant | Matters to the goal | Directly linked to outcome |
| **T** — Time-bound | By when | "by December 2026" |

### Bad Target Examples

- "Improve maternal health" — not measurable
- "Reach as many people as possible" — not specific
- "Reduce malnutrition significantly" — not measurable or time-bound

### Good Target Examples

- "400 pregnant women receive 4+ ANC visits by December 2026"
- "85% of children 6-59 months screened for malnutrition in District X by project end"
- "25 community health committees established in Camp A by Q2 2026"

## Baseline vs Cumulative vs Period

| Term | Meaning |
|------|---------|
| **Baseline** | Value at project start (usually 0) |
| **Cumulative** | Total from start to now |
| **Period value** | Just this reporting period |

Example:
- Baseline (Jan 2026): 0
- Q1 value (Jan-Mar): 45 women
- Q2 value (Apr-Jun): 75 women
- Cumulative at end of Q2: 120 women (45 + 75)

## Disaggregation

Break down indicators by groups to understand who is being reached:

| Group | Example |
|-------|---------|
| Male / Female | 30 men, 70 women |
| Age | 50 adults, 20 children |
| Disability | 5 people with disabilities |
| Location | 60 urban, 40 rural |

DonorDesk supports disaggregation for:
- Male / Female / Children / Disability

## Verifying Indicators

Indicator updates go through a verification process:

1. **Draft** — Value entered but not submitted
2. **Submitted** — Sent for review
3. **Verified** — Reviewed and confirmed correct

Only verified values appear in final reports and exports.

## Indicator Categories

### Output Indicators

Measure the products/deliverables of your project:
- Number trained
- Number of sessions conducted
- Number of facilities equipped

### Outcome Indicators

Measure the changes your project contributes to:
- % of population with access
- Behaviour change rates
- Service utilisation rates

### Process Indicators

Measure how you are working:
- % of planned activities completed
- Budget utilisation rate

## Common Mistakes

### Confusing Activity with Indicator

**Wrong:** "Number of training sessions conducted" as an outcome indicator

**Right:** "Number of people trained" as an outcome, "Number of sessions" as an activity measure

### Too Many Indicators

More is not always better. 10-15 well-chosen indicators is better than 50 poorly tracked ones.

### Indicators Without Evidence

Every indicator needs a means of verification. Ask:
- How will we measure this?
- What evidence will prove it?
- Is the evidence realistic to collect?
