# How to Use Comments and Feedback

The comments feature in DonorDesk lets your team communicate within reports, evidence, and other items.

## Where You Can Comment

Comments can be added to:
- Report sections
- Evidence files
- Indicator updates
- Compliance checklist items
- Activity updates

## How to Add a Comment

### On a Report Section

1. Open the report draft
2. Find the section you want to comment on
3. Click the **comment** icon or highlight text
4. Type your comment
5. Click **Add Comment**

### On Evidence

1. Open the evidence file
2. Click **Add Comment**
3. Type your feedback
4. Submit

### On Indicators

1. Go to the Indicators tab in a reporting period
2. Click on an indicator row
3. Add a note or comment
4. Save

## Comment Features

### Mentioning Team Members

Tag a colleague to notify them:

1. Type `@` in the comment box
2. Start typing their name
3. Select their name from the list
4. They will receive a notification

### Comment Status

| Status | Meaning |
|--------|---------|
| **Open** | Comment has not been addressed |
| **Resolved** | The issue has been addressed |

### Comment Threading

If someone replies to your comment, it creates a thread. You can:
- Reply to continue the conversation
- Resolve when the issue is fixed
- Delete your own comments

## Best Practices for Comments

### Do:

- Be specific about what needs to change
- Use comments to ask questions, not make demands
- Resolve comments when addressed
- Use @mentions to involve the right people

### Do Not:

- Use comments to communicate sensitive personal data
- Leave resolved comments open
- Write essays in comments — keep them focused

## Comment Notifications

When you are mentioned in a comment:
- You receive an in-app notification
- If email notifications are enabled, you get an email

## Comment Moderation

Only the person who wrote a comment can:
- Edit their own comment
- Delete their own comment

Admins and Owners can delete any comment.

## Comment History

All comments are saved and form part of the audit trail. Deleted comments are removed from view but may be retained in audit logs.

## Exporting Comments

Comments are included in the report export history. They are part of the approval audit trail.
