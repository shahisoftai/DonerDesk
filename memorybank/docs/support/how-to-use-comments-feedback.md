# How to Use Comments and Feedback

Comments keep review conversations next to the thing being discussed.

## In the report editor

1. Select a section in the outline.
2. Open the **Comments** tab in the section inspector.
3. Click **Add a comment**, write your message.

Reviewers use comments to explain what to change. When a reviewer chooses **Request changes** they write the reason, and the author gets a **Report returned** notification.

## Who can comment

Admin, Project Manager, M&E Officer, Grants Officer, Field Officer and Compliance Officer. Viewers are read-only.

## Other feedback

- **Activities:** reviewers must add a note when they send a revision request or reject an update.
- **Compliance items:** notes are required when resolving an item and are kept with it.
- **Statements:** when you keep a flagged statement you add a note explaining why it is acceptable.
- **Indicators and evidence:** *Needs correction* and *Rejected* decisions carry a reason.

All comments, notes and decisions are stored in the [audit trail](/support/how-to/use-the-audit-trail).
