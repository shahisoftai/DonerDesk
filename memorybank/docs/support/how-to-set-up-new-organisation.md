# How to Set Up a New Organisation in DonorDesk

This guide walks an admin through setting up a new organisation workspace in DonorDesk.

## Step 1: Create Your Account

If you do not have an account yet:

1. Go to **https://donordesk.online**
2. Click **Sign up**
3. Enter your details
4. Verify your email

## Step 2: Complete the Setup Wizard

After first login, the setup wizard will guide you through:

### Connect Google Drive (Optional)

1. Click **Connect Google Drive**
2. Authorise DonorDesk to access your Google Drive
3. Select the root folder for DonorDesk files
4. Click **Confirm**

This is optional but recommended for evidence storage.

### Organisation Profile

1. Enter your organisation name
2. Select your organisation type
3. Choose your country
4. Select your primary sector
5. Add contact details

### Default Reporting Profile

1. Choose default report tone (Formal, Technical, Accessible, Simple)
2. Select default language
3. Set deadline offset (days before donor deadline for internal review)
4. Configure auto-period creation if needed

### Invite Your Team (Optional)

You can skip this and invite team members later. To invite now:

1. Enter email addresses
2. Assign roles
3. Select projects
4. Click **Send Invitations**

### Accept Terms

1. Read the Terms of Service
2. Read the Privacy Policy
3. Accept both

## Step 3: Configure Organisation Settings

After the wizard, fine-tune your settings:

### General Settings

1. Go to **Settings → Organisation**
2. Upload your logo
3. Complete all profile fields
4. Add your website and social links

### Storage Settings

1. Go to **Settings → Storage**
2. Choose your storage method:
   - **Google Drive (link-first)** — Recommended
   - **Local/R2** — Files stored by DonorDesk
3. If using Drive, review folder structure

### Notification Settings

1. Go to **Settings → Notifications**
2. Configure organisation-wide notification defaults
3. Set up admin notification preferences

## Step 4: Create Your First Project

See the "How to Create a Project" guide for detailed steps.

Quick start:

1. Click **Create Project**
2. Enter basic details (name, donor, dates)
3. Upload donor template if you have one
4. Build your logframe
5. Create your first reporting period

## Step 5: Configure Team Access

### Invite Team Members

1. Go to **Settings → Team → Invite Member**
2. Enter email and role
3. Assign to relevant projects
4. Send invitation

### Set Project Permissions

For each project:
1. Go to the project → **Team**
2. Add team members
3. Set their project-level roles
4. Define what they can access and edit

## Step 6: Set Up Templates

### Create or Upload Templates

1. Go to **Templates**
2. Either:
   - Upload a donor template file (PDF, DOCX)
   - Create a manual template
3. Name and save the template

### Configure Donor-Specific Templates

For each donor:
1. Upload their specific template
2. Map sections if needed
3. Link to relevant projects

## Step 7: Establish Workflows

### Approval Workflow

1. Determine who approves reports
2. Set up reviewer assignments
3. Define escalation paths

### Compliance Checking

1. Configure compliance rules
2. Set default severity levels
3. Assign compliance responsibilities

### Notification Triggers

1. Set up deadline reminders
2. Configure compliance alerts
3. Enable team activity notifications

## Step 8: Test the System

Before going live:

1. Create a test project
2. Upload sample evidence
3. Log a test activity
4. Update a test indicator
5. Generate a draft report
6. Export the report

This ensures everything works before real data.
