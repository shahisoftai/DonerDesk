# How to Prepare for a Donor Visit

Donor visits require preparation to showcase your work effectively. Here is how to use DonorDesk to get ready.

## Timeline for Preparation

### 4 Weeks Before

1. Review donor agreement and requirements
2. Identify what the donor wants to see
3. List any data gaps
4. Assign preparation tasks

### 2 Weeks Before

1. Update all indicator values
2. Upload any pending evidence
3. Generate draft reports
4. Review compliance checklist

### 1 Week Before

1. Complete data entry
2. Verify all evidence
3. Prepare site visit documentation
4. Brief field staff

### Day Before

1. Final check of all data
2. Print necessary documents
3. Confirm visit schedule
4. Resolve any open items

## What to Have Ready

### For Desk Reviews

#### Programme Documents
- Project proposal and logframe
- Latest progress reports
- M&E framework
- Work plans

#### Evidence
- Evidence library organised by donor requirement
- Verification status confirmed
- Key evidence easily accessible

#### Data
- Indicator tracking table (baseline, target, actual)
- Data quality assessment
- Any evaluations or assessments

### For Field Visits

#### Site-Level Data
- Site-specific activities and outputs
- Beneficiary lists (if appropriate)
- Photos and success stories
- Site monitoring reports

#### Organisation Materials
- Organisational structure
- Staff list and roles
- Financial reports
- Policies (child protection, gender, etc.)

## Using DonorDesk for Preparation

### 1. Run the Readiness Report

1. Go to your reporting period
2. Check the readiness score
3. Focus on low-scoring areas

### 2. Generate a Quick Summary

1. Go to **Reports → [Period] → Overview**
2. Export indicator summary
3. Pull key achievements

### 3. Organise Evidence

1. Go to **Evidence**
2. Filter by donor requirements
3. Verify key files are accessible
4. Prepare evidence checklist

### 4. Prepare Talking Points

Use the dashboard to identify:
- Key achievements since last visit
- Challenges and how they were addressed
- Updates since last report
- Plans for next period

## What Donors Typically Ask

### Programme Questions

- What have been the main achievements?
- What challenges have you faced?
- How do you track progress against targets?
- What is working well?
- What needs to change?

**Preparation:** Review your logframe, indicators, and latest report draft.

### Financial Questions

- How much has been spent?
- Are there any variances from budget?
- How is value for money being achieved?
- What are the remaining funds for?

**Preparation:** Have financial tracking available (separate from DonorDesk).

### Evidence Questions

- Can you show evidence for [specific claim]?
- How do you verify this data?
- Who collected this data?
- How do you ensure quality?

**Preparation:** Organise evidence by indicator and donor requirement.

### Partnership Questions

- How do you coordinate with partners?
- What is the division of responsibilities?
- How do you manage partner reporting?

**Preparation:** Have partnership agreements and coordination meeting minutes ready.

### Field Staff Preparation

1. Brief staff on donor visit objectives
2. Assign specific responsibilities
3. Prepare field-level data summaries
4. Brief on key messages and facts
5. Review beneficiary consent procedures

## During the Visit

### Using DonorDesk Live

If you have internet access during the visit:

1. Show real-time data in DonorDesk
2. Demonstrate the evidence library
3. Walk through indicator tracking
4. Access specific documents on request

### Offline Preparation

If internet may be limited:

1. Export key documents as PDF
2. Download indicator summaries
3. Save key evidence locally
4. Prepare printed copies of critical items

## Post-Visit Follow-Up

After the donor visit:

1. Document any questions asked
2. Note feedback received
3. Update DonorDesk with new information
4. Address any items requiring follow-up
5. Send thank you with requested information
