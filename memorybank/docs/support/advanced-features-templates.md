# Advanced: Using Report Templates and Donor-Specific Formatting

If you work with multiple donors, each with their own report format, you can set up templates to ensure your reports always match donor expectations.

## Creating a Donor Template

### Step 1: Get the Donor Template

Obtain the report template from your donor — usually a Word or PDF file they have provided.

### Step 2: Upload to DonorDesk

1. Go to your project → **Templates** tab
2. Click **Upload Template**
3. Select the donor's file (PDF, DOCX, DOC)
4. DonorDesk extracts the sections automatically

### Step 3: Review Sections

After upload, review each extracted section:
- Rename sections if needed
- Delete sections that do not apply
- Reorder to match the donor's preferred structure

### Step 4: Link to Requirements

For each section, you can link to:
- Donor requirements document
- Compliance checklist items
- Specific logframe outputs

This helps DonorDesk understand what belongs in each section.

## Multiple Templates

You can have multiple templates for the same project:

| Use case | Template |
|---------|---------|
| Standard quarterly report | UNICEF template |
| Annual report | EU template |
| Narrative report | Internal template |

When creating a reporting period, select which template to use.

## Custom Section Templates

You can also create custom sections that follow a specific format:

### Step 1: Create a New Section

1. Go to **Templates → Add Section**
2. Name the section (e.g., "Beneficiary Testimonials")

### Step 2: Add Guidance Text

In the section, add guidance that appears when someone edits it:

```
This section should include:
- 2-3 direct quotes from beneficiaries
- Photos of beneficiaries (if consent is given)
- Demographic breakdown of quote givers
```

AI generation will take this guidance into account.

## Auto-Population Rules

You can set rules for how certain sections are auto-filled:

| Rule | What it does |
|------|-------------|
| **Pull from indicator** | Fills a section with the latest indicator values |
| **Pull from activities** | Summarises recent activities in this section |
| **Pull from evidence** | Lists linked evidence in this section |

## Donor-Specific Tone

Some donors prefer different writing styles. You can configure tone in **Settings → AI Settings**:

| Tone | When to use |
|------|------------|
| **Formal** | Standard donor reports, EU, UN agencies |
| **Technical** | Research donors, academic funders |
| **Accessible** | Public donors, government funders |
| **Simple** | Small foundations, community donors |

## Sections That Require Human Input

Some sections cannot be generated by AI and must be written by a person:

- Executive summary (requires strategic overview)
- Financial summary (requires finance team input)
- Donor-specific annexes

Add these as manual sections in your template.

## Export Formatting Options

When exporting, you can choose:

| Option | What it does |
|--------|-------------|
| **Include logo** | Adds your organisation logo to the header |
| **Include project code** | Adds the project code to the header |
| **Page numbering** | Adds page numbers |
| **Donor branding** | Uses the donor's preferred header/footer format |
| **A4/Letter** | Choose paper size for PDF export |

## Template Versioning

When a donor updates their template format:
1. Go to **Templates**
2. Click on the template
3. Click **Upload New Version**
4. Select the updated file
5. Review the new sections

New reporting periods will use the updated template. Existing periods keep the old template version.
