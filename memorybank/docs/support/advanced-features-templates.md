# Donor Templates: Advanced Tips

The basics are in [How to upload a donor template](/support/how-to/upload-donor-template). These tips help with tricky templates.

## Getting good extraction

- Prefer the donor's **Word** file: headings and tables are read best. Templates with no heading styles are handled by reading font size, boldness and colour.
- Scanned PDFs cannot be read. Paste the text instead.
- Use **Extract and review**, then check the outline and required sections carefully before **Approve template**.

## Reviewing well

- Confirm the **hierarchy** (parent and child sections).
- Check each section's **instructions, mandatory questions, evidence needed, required tables and page limit**.
- Mark sections that are only guidance as **not included in the report**.
- Add your own **author instructions** where your organisation has a house style. The AI Reporter uses them.
- Edit **Report requirements** for report-wide rules.
- Use **AI brief preview** to see what the writer will be told.

## Versions and defaults

Each edit is a new version (see **Version history**). A reporting period keeps the version it was created with. Set a **project default** template so new periods pick it automatically, and **save it to the library** to reuse in other projects.

## Donor-native output

For donors who require their own Word document, open the template's **mapping** page: upload the original .docx, assign regions to sections, review every region, approve, and lock it to a period.

## If extraction fails

Retry, paste the text, or choose **Build the sections myself**. If the same document fails repeatedly, email support@donordesk.online with the file.
