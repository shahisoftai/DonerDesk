# Troubleshooting Browser and Performance Issues

## Slow Performance

### DonorDesk Loads Slowly

1. **Check your internet speed** — Run a speed test
2. **Try a different browser** — Chrome, Firefox, Edge, or Safari
3. **Clear browser cache** — Settings → Privacy → Clear cache
4. **Disable extensions** — Some browser extensions slow down DonorDesk
5. **Try incognito mode** — Rules out extension conflicts

### Specific Pages Load Slowly

| Page | Possible cause | Solution |
|------|---------------|----------|
| Dashboard | Too many projects | Filter to active projects only |
| Evidence library | Large files | Use Google Drive linking |
| Report generation | Large data set | Generate sections individually |
| Export | Large evidence pack | Export in batches |

### Generation Times Out

AI report generation can take 1-2 minutes for large reports. This is normal. Wait for completion or:
- Try generating individual sections
- Reduce the amount of data
- Try during off-peak hours

- Edge: ⋯ → Help and feedback → About Microsoft Edge → Update

## Page Display Issues

### Page Looks Broken

1. **Clear browser cache**
2. **Refresh the page** (F5 or Ctrl+R)
3. **Try a different browser**
4. **Zoom level** — Press Ctrl+0 to reset

### Images or Charts Not Displaying

1. **Check internet connection**
2. **Clear cache and refresh**
3. **Try a different browser**
4. **Check if the file is supported** (JPG, PNG for images)

### PDF Preview Not Working

PDF preview requires your browser to support PDF display. If it does not work:
1. Download the PDF instead
2. Open in a PDF viewer
3. Try a different browser

## File Upload Problems

### Upload Button Not Working

1. **Check browser permissions** — Allow popups from donor-desk.online
2. **Clear cache and refresh**
3. **Try a different browser**
4. **Check file size** — May exceed limits

### Upload Freezes or Hangs

1. **Check file size** — Large files may take time
2. **Check internet connection** — Weak connection causes issues
3. **Try a smaller file first** — Test with a small document
4. **Use Google Drive linking** — For very large files

## JavaScript Errors

### "JavaScript error" Appears

1. **Refresh the page**
2. **Clear cache**
3. **Try a different browser**
4. **Disable browser extensions** temporarily

If the error persists, contact support with:
- The exact error message
- What you were doing when it occurred
- Your browser version

## Mobile Browser

DonorDesk is optimised for desktop. Some features may not work on mobile.

### If on Mobile

1. Use landscape mode
2. Request desktop site option
3. For data entry, use a desktop or tablet

## Checking Browser Version

### Chrome
Type in address bar: `chrome://settings/help`

### Firefox
Type in address bar: `about:support`

### Edge
Type in address bar: `edge://settings/help`

## When to Contact Support

Contact **support@donordesk.online** if:
- Issues persist after trying these steps
- You see error messages not covered here
- Performance is consistently poor
- You cannot access DonorDesk at all

Include:
- Browser name and version
- Operating system
- Steps to reproduce the issue
- Screenshots if possible
