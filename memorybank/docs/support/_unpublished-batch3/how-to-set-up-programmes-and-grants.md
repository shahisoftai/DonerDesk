# How to Set Up Programmes and Grants

A **programme** groups related projects, for example a country programme. A **grant** is one award from a donor: its title, the donor, the amount and the dates. A project can sit under a grant, which places it in that grant's programme as well.

Only an Admin can add or change programmes and grants.

## Add a programme

1. Open **Programmes and grants** (from the Projects page).
2. Under **New programme**, type a name and select **Add programme**.

Programme names must be unique in your organisation.

## Add a grant

1. Under **New grant**, type the grant title and the donor's name.
2. Optionally choose a programme, the award amount and its currency (a three-letter code such as USD or EUR), then select **Add grant**.

The amount must be a positive number. The currency is required when there is an amount.

## Put a project under a grant

Projects that are not under a grant or programme are listed under *Projects not under a grant or programme*. Choose the grant from the list next to the project.

## Reading the totals

Each programme shows how many projects it has (and how many are active), the project budgets and the amounts awarded. Totals are shown per currency and are never added across currencies. A project with no budget is not counted as zero. Totals include only the projects you are allowed to see.
