# Advanced: Using Project Templates

Project templates let you save time by reusing project structures. Create a template once and use it for multiple projects.

## What Is a Project Template?

A project template includes:
- Project structure (logframe hierarchy)
- Standard indicators with targets
- Reporting period schedule
- Team roles

It is not a full project — you still need to add donor-specific details.

## When to Use Templates

### Good use cases:
- Multiple projects with the same donor (e.g., EU-funded projects)
- Standard sector templates (e.g., nutrition programme structure)
- Replication across different locations
- Starting point for new projects

### Not needed for:
- One-off projects
- Very donor-specific requirements
- Unique project structures

## Creating a Project Template

### Step 1: Build a Reference Project

1. Create a project with the structure you want to replicate
2. Add the logframe with indicators
3. Set up reporting periods
4. Add team role templates

### Step 2: Export as Template

1. Go to the reference project
2. Go to **Settings** or **Export**
3. Click **Export as Template**
4. Name the template (e.g., "UNHCR Nutrition Programme Template")
5. Choose what to include:
   - Logframe structure
   - Indicator definitions
   - Reporting period schedule
6. Click **Export**

### Step 3: Save the Template

The template is saved to your organisation's template library.

## Using a Template for a New Project

### Step 1: Start New Project

1. Go to **Projects**
2. Click **New Project**
3. Select **Use Template**

### Step 2: Choose a Template

1. Browse your organisation's templates
2. Select the template you want to use
3. Preview the structure

### Step 3: Customise

After selecting a template:
1. Add project-specific details (donor name, dates, location)
2. Adjust indicators if needed
3. Keep or modify the logframe structure

### Step 4: Create

Click **Create Project**.

The new project has the template structure but with your custom details.

## Template Library

### Accessing the Library

1. Go to **Settings → Templates**
2. See all organisation templates

### Managing Templates

| Action | How to do it |
|--------|-------------|
| View template | Click on the template name |
| Edit template | Click **Edit** and make changes |
| Duplicate template | Click **Duplicate** |
| Delete template | Click **Delete** (confirm) |

## Template Best Practices

### Keep Templates Simple

Start with the basic structure and add details per project. A template should be:
- A starting point, not a complete project
- Focused on replicable elements
- Easy to customise

### Version Your Templates

If you update a template:
1. Create a new version (e.g., "Nutrition Template v2")
2. Keep the old version for existing projects
3. Use the new version for new projects

### Document Template Assumptions

Add a description to each template explaining:
- What donor it was designed for
- What assumptions were made
- What should be customised per project

## Limitations of Templates

Templates do not include:
- Evidence files (upload fresh for each project)
- Activity logs (specific to each project)
- Actual indicator values (start fresh)
- Team members (invite fresh)

## Example Template: Standard Nutrition Programme

```
Project Template: Nutrition Programme
Donor: UNHCR Standard
Sector: Nutrition
Duration: 12 months
Reporting: Quarterly

Logframe:
Goal: Reduce malnutrition among children under 5 and pregnant/lactating women

OUT-1: Improved infant and young child feeding practices
  OUT-1.IND-1: Number of caregivers trained in IYCF
  OUT-1.IND-2: % of children 6-23 months receiving minimum dietary diversity
  
OUT-2: Increased access to nutrition services
  OUT-2.IND-3: Number of SAM children admitted to OTP
  OUT-2.IND-4: % of PLW screened for malnutrition

Reporting Schedule:
- Q1: Jan-Mar (due Apr 15)
- Q2: Apr-Jun (due Jul 15)
- Q3: Jul-Sep (due Oct 15)
- Q4: Oct-Dec (due Jan 15)
- Annual: Jan-Dec (due Feb 28)
```
