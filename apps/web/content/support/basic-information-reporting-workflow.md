# Understanding the Reporting Workflow

DonorDesk turns your project data into a donor-ready report in a repeatable cycle. This page shows the whole journey.

## One-time project setup

1. **Create the project** with the project wizard (ten short slides: start, team, results, indicators, places, work plan, data entry, reporting, budget, launch). Progress is saved as a draft if you leave, and nothing exists until you press **Start the project**.
2. **Finish setup** on the project's Setup checklist: project workspace folder (Google Drive), **donor template** reviewed and approved, **logframe and indicators**, **reporting profile** (language, tone, rules) and team assignment (recommended).
3. When every blocker is cleared the project is **ready for reporting** and you can create reporting periods. Activate the project (a new project starts as a Draft) and confirm how each indicator is calculated; the Setup page lists indicators still waiting for that as a warning.

The [Academy tour](/tour) walks through this on a demo project.

## Each reporting period

Every reporting period has a workspace. It opens on **Ready to write this report**, which lists what the AI will write from (**Indicator values**, **Story answers**, **Evidence**) with a **Generate report** button. The work falls into four stages:

| Stage | What you do |
|---|---|
| **1. Enter your data** (**Indicator values**) | Enter indicator values in the Report inputs sheet (or import from Excel or Google Sheets), log activities, upload and link evidence, verify data. |
| **2. Tell the story** (**Story answers**) | Answer the story questions: what went well, challenges, why targets were over/under achieved, what changed, and a lesson or story. |
| **3. Generate the report** (**Generate report**) | The AI Reporter writes the report section by section following the donor template. |
| **4. Review and submit** | Edit in the document-style report editor, decide on flagged statements, approve sections, clear the checks, submit for review, approve, and export. |

## The report editor

The editor shows one continuous document with an **outline** on the left (with a progress count), the **section inspector** on the right (Statements, Sources, Chart, Comments, History) and a **single primary button** that always shows the next step: *Generate report → Review n flagged statements → Approve n remaining sections → Finish remaining checks → Submit for review → Approve report → Export report*.

## Approval and export

The report moves through **Draft → Under review → Approved → Exported → Submitted**. Approval and export run through the same gate: unresolved blocking issues (unsupported material claims, numeric contradictions, confidentiality violations, stale verifications and similar) must be fixed or explicitly accepted by someone with the right authority. Exports come in two kinds: a **watermarked internal** copy and a **donor submission** copy bound to a sealed snapshot of the approved report.

## Where the time goes

Setup happens once per project. After that, each period is: enter data, tell the story, generate, review, export.
