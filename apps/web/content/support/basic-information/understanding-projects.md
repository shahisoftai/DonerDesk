# Understanding Projects

A **project** is one funded grant or programme. It holds the logframe, indicators, activities, evidence, donor template(s), team assignments and reporting periods.

## Key fields

Title, project code, donor name, implementing and partner organisations, country/region/district, sector, start and end dates, reporting frequency, budget and currency, contact and description.

## Project pages

| Tab | Purpose |
|---|---|
| **Reporting** | Reporting periods and the report workspace (the main working area). |
| **Overview** | Summary, readiness and next actions. |
| **Logframe** | Hierarchy and indicators. |
| **Activities** | Field updates. |
| **Evidence** | Project evidence library. |
| **Templates** | Donor templates. |
| **Team** | Project assignments and project roles. |
| **Settings** | Details, dates, budget, status, archive. |

The **Setup** page (linked from the project) is the checklist for getting ready to report.

## Status

| Status | Meaning |
|---|---|
| Draft | Just created. |
| Active | In progress. |
| Paused | Reporting suspended. |
| Completed | Ended; no new reporting periods. |
| Archived | Read-only; does not count toward plan limits. |

## Limits

Only **active** projects count toward your plan: Starter 1, Team 5, Growth 20. Archived projects and the Academy demo project do not. See [Plans and limits](/support/account-billing/plans-and-limits).

## Setup readiness

A project is **Ready** to report when it has a provisioned workspace folder, a donor template with reviewed required sections, complete indicators and a reporting profile. See [Report readiness](/support/getting-started/report-readiness).

## One project or several?

Use **one project per grant**. If one programme has several donors with different formats, create one project per donor so each has its own template, indicators and reporting cycle. See [Multiple donors](/support/advanced-features/multiple-donors).

Create one: [How to create a project](/support/how-to/create-a-project).
