# Logframe Hierarchy

DonorDesk uses four levels: **Goal → Outcome → Output → Activity**.

```
Goal
└── Outcome
    └── Output
        └── Activity
```

## Rules

- Each item has one parent (except top-level items).
- Every item has a unique **code** within the project.
- A goal can have several outcomes, an outcome several outputs, and so on.
- Indicators attach to any level, usually outcomes and outputs.

## Working with the tree

- **Drag** an item to reorder it, or drop it on another to change its parent.
- Use **Move to** (including **top level**) if you prefer menus or a keyboard.
- The order you set is kept and used in the indicator table and reports.

## Importing

The Excel template's **Logframe** sheet has one row per item with a code, level, title and parent code. Existing codes are skipped, so re-importing is safe. See [How to build a logframe](/support/how-to/build-logframe).
