# How to Check Your Portfolio

> The portfolio page shows every live project you can see on one page, with the ones that need you first.

## Open the portfolio

Select **Projects**, then **Portfolio dashboard**. You see only the projects you are a member of.

## Read a row

Each project has one row:

- **Delivery**: On track, Needs attention, Behind, or No plan yet, with the main reason and the number of late activities and overdue indicator values.
- **Problems and risks**: how many are open, how many are serious, and how many are past their review date.
- **Next report**: the nearest unfinished report, how many days are left (or how many days overdue), its status and readiness.

The top tiles count projects, those behind, those needing attention, open and serious problems, and overdue reports. Select a project name to open it.

Projects are ordered so that the ones needing attention come first. There is no overall score: read each column for what it counts.

## Indicators across projects

Select **Indicators across projects** to add up verified indicator values per donor. Projects that are not measured are shown as "Not measured", never as zero.

## Avoid counting people twice

If two projects in the same country run at the same time and both count the same people, the total may count them twice. DonorDesk then adds a note under that indicator.

If they really do count the same people, open the indicator on one of the projects, select **Edit**, and tick **Another project also counts these people or things**. That project's value is then listed but not added to the total.

## Good to know

- Archived and completed projects are not shown.
- Use **Download as a spreadsheet** on the indicators page to take the totals out of DonorDesk.
