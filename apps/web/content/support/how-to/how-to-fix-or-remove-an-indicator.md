# How to Fix, Move or Remove an Indicator

You no longer need to rebuild a project because of an indicator mistake. Open the indicator and change it. Who can: **Admin**, **Project Manager** and **M&E Officer**.

Open **Projects → your project → Logframe**, then click the indicator to open its page. Below the calculation settings you will see **Edit indicator**.

## Fix the wording or the numbers

1. Change the **code**, **name**, **unit**, **baseline** or **target**.
2. Click **Save changes**.

Every change is recorded in the audit trail (what it was, what it is now).

## Turn the breakdown on or off

Tick **Record a breakdown by sex, age group and disability** and save. The values grid then shows a **Breakdown** button for this indicator. New indicators that count people (people, households, children, participants…) have it ticked for you; you can untick it.

## Move an indicator to the right place

Picked the wrong goal, outcome, output or activity? Under **Measures**, choose the right logframe item and click **Move indicator**.

- It must stay inside the same project.
- Its values, evidence and history move with it.
- If a report that used this indicator is already **approved**, the move is refused and the message says so. Ask a reviewer to send the report back with **Request changes** first.

## Change its type

You can change the type (for example Number to Percentage) only while no value has been recorded. After that the type is locked, because the old values were entered in the old type. Archive the indicator and add a new one.

## Remove an indicator

Click **Remove indicator** and confirm.

| If the indicator has… | What happens |
|---|---|
| No values recorded | It is **deleted**. |
| Values recorded | It is **archived**: hidden from the logframe, grids and new reports, but its history is kept. |
| Values used in an **approved** report | It cannot be removed. Ask a reviewer to send the report back with **Request changes** first. |

## Bring an archived indicator back

An archived indicator is hidden, not lost.

1. Open **Logframe**. Below the indicators table, **Archived indicators (n)** lists each one with the date it was archived. (The list only appears when there is something archived.)
2. Click **Restore** next to the indicator.

It returns to the logframe, the values grid and new reports with all its values and history. If another indicator now uses the same **code**, the restore is refused and tells you which code; change one of the codes first, then restore.

## Several indicators under one logframe item

When you import indicators, add an optional column called **Logframe Code** (it is the last column of the downloadable template). Put the code of the logframe item the indicator measures. Without that column, the indicator's own code must match the item's code, so each item could only carry one indicator. See [How to build a logframe](/support/how-to/build-logframe).
