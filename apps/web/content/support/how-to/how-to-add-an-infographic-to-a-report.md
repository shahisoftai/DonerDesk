# How to Put an Infographic in a Report

1. Open the report section's editor and choose **Add an infographic**.
2. Pick a design. It is inserted as a snapshot.
3. The same rules as report charts apply: the section must be a draft, and an approved section is reopened first.

Writers never receive infographic data. To refresh it, add it again. See also [add a chart to a report](/support/how-to/add-a-chart-to-a-report).
