# How to Build a Table of Results with the Report Builder

A saved report is a question, never the figures: which indicators, which periods, which measure. It is worked out again from the data each time.

## Build one
1. Open the project's **Data** area and choose **Report builder**.
2. Tick the **indicators**, choose the **first and last period**, the **measure** (period value, cumulative or percent of target) and what goes in the rows (indicators or periods).
3. Choose whether values that are **not verified yet** are included. They are counted in a note under the table.

## Read the table
- A missing value shows **Not measured**. A real zero shows **0**.
- Nothing is added up across indicators.
- A rate has no percent of target.

## Show a breakdown
With the measure set to **period value** and rows set to **indicators**, choose **Breakdown** to show the recorded groups (for example sex or age) across the columns for the last period in your range. The total shown is the recorded total, never the sum of the groups.

## Save, share and download
- **Save** it as **Mine** or **Project** (same rules as [saved charts](/support/how-to/save-and-reuse-a-chart)).
- **Download CSV**. A cell that starts with = + - or @ is made safe so a spreadsheet will not run it as a formula.
- Add a saved report to a dashboard as a table block.
