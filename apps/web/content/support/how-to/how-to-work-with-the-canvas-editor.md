# How to Edit a Design: Selection, Commands and Shortcuts

Click **Edit** on a design.

## Select and arrange
- Click a block, or select several. Align, distribute, group, lock or reorder them. One gesture is one undo step.
- A locked block is never moved; it is named if it was skipped.

## Copy and paste
Copy and paste carries the block's settings, never figures. Pasting checks the kinds, limits and the projects you may see.

## Command palette and shortcuts
Open the **command palette** to search every action. The shortcut sheet lists the keys. The same commands drive the toolbar, the palette and the keyboard.

## Undo and versions
History keeps 200 steps. Every save keeps the document it replaced; the last 30 can be restored as an undoable edit.

## See your edit before saving
Blocks show real project figures while you edit, read as you.

## Work with others
The names of other people who have the design open appear at the top. This is only live; nothing is stored. If two people save, the second is refused instead of overwriting.
