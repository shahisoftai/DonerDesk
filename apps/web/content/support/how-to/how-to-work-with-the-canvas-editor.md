# How to Edit a Design: Selection, Commands and Shortcuts

Click **Edit** on a design.

## Select and arrange
- Click a block, or select several. Align, distribute, group, lock or reorder them. One gesture is one undo step.
- A locked block is never moved; it is named if it was skipped.

## Copy and paste
Copy and paste carries the block's settings, never figures. Pasting checks the kinds, limits and the projects you may see.

## Command palette and shortcuts
Click **Commands** (or press **Ctrl+K**) to search every action; actions that do not apply to what you selected say *Not available now*. Click **?** for the shortcut sheet. The same commands drive the toolbar, the palette and the keyboard. The main keys:

| Action | Keys |
|---|---|
| Undo / Redo | Ctrl+Z / Ctrl+Shift+Z |
| Copy / Cut / Paste / Duplicate | Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D |
| Delete, Select all | Delete, Ctrl+A |
| Align left / centres / right | Alt+A / Alt+H / Alt+D |
| Align top / middles / bottom | Alt+W / Alt+V / Alt+S |
| Space evenly across / down | Alt+Shift+H / Alt+Shift+V |
| Bring to front / forward, Send backward / to back | Ctrl+Shift+] / Ctrl+] / Ctrl+[ / Ctrl+Shift+[ |
| Group / Ungroup | Ctrl+G / Ctrl+Shift+G |
| Lock / Unlock, Hide / Show | Ctrl+L / Ctrl+Shift+L, Ctrl+H / Ctrl+Shift+H |
| Zoom in / out | Ctrl+= / Ctrl+- |
| Fit page / Actual size | Shift+1 / Shift+0 |
| Grid, Rulers | Ctrl+' , Ctrl+Shift+R |
| Save / Preview | Ctrl+S / Ctrl+P |

The first time you edit, a short tour (*1 / 5 Add blocks* …) offers **Next** or **Skip**.

## Undo and versions
History keeps 200 steps. Every save keeps the document it replaced; the last 30 can be restored as an undoable edit.

## See your edit before saving
Blocks show real project figures while you edit, read as you.

## Work with others
The names of other people who have the design open appear at the top. This is only live; nothing is stored. If two people save, the second is refused instead of overwriting.
