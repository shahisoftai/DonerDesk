# How to Draw Distribution, Flow and Composition Charts

Pick these in the **Charts** tab, under **Chart type**. A type that your data cannot honestly show is greyed out; point at it to see why.

| Chart | Use it to | It needs |
|---|---|---|
| **Beeswarm** | See every recorded value as a dot | Counts, enough values |
| **Violin** | See the shape of how values spread | Enough values. The shape is an estimate; the dots are the recorded values |
| **Ridgeline** | Compare spreads across periods | Counts, several periods |
| **Marimekko** | Show a split and its parts together | A recorded split. Widths are the recorded totals. It has no data table |
| **Alluvial** | Follow spent money from budget to result | Budget data. A result nobody read is left out and counted |
| **Chord** | See flows between categories | Budget data |
| **Parliament** | Show shares as seats | Counts that add up |
| **Proportion bar** | Show shares in one bar | Counts that add up |
| **Small multiples** | Repeat one chart per indicator | Indicators in the same unit |
| **Dot density** | Place dots on a map, each standing for a stated number | Places with pins |
| **Hexagon grid map** (hex grid) | Sum values into hexagons | Places with pins. A place is never added to the area that contains it |

## Rules these charts follow
- Rates (percentages, ratios) are never stacked, sliced or summed.
- Two units never share one axis.
- A gap is a gap, never zero.
- When a chart is refused you get a plain reason and, where possible, a one-click fix.

## Not offered
A population pyramid, error bars and word clouds are not offered. Breakdowns are recorded one dimension at a time, no interval is recorded for error bars, and files cannot draw word clouds.
