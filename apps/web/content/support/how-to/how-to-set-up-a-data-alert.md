# How to Set Up an Alert on an Indicator

1. Open **Dashboards and infographics**, then **Tools ▾ → Data alerts**.
2. Choose an indicator and a limit.
3. Save.

## How it works
- Alerts are checked every hour as **you**. If you lose access to the project, you stop being told.
- You are told **once** each time the indicator crosses into the limit, not every hour.
- A rate (a percentage or ratio) is never judged as a percent of target.
- A value marked **not applicable** counts as no figure.
- The message names the indicator and the figures only.
