# How to Get a Management Report

> The management report shows where one project stands on one page: delivery, indicators, reports, problems and risks, and evidence. You can read it on screen or download it as a spreadsheet.

## Open it

Open the project, go to **Reports**, and select **Management report**.

## What is on it

1. **Project**: title, code, donor, country, sector, dates and status.
2. **Delivery**: whether the project is on track, planned and late activities, overdue indicator values, completed activities, accepted ones, and the number of people reached in accepted activities.
3. **Indicators**: target, latest recorded value and its date, percentage of target, variance against any target schedule, and status. An indicator with no recorded value says **Not measured**.
4. **Reports**: each reporting period with its status, deadline, days to the deadline and readiness.
5. **Problems and risks**: what is open, how serious it is, and when it should be reviewed.
6. **Evidence**: how many files are verified, pending, corrected or rejected.

Each section starts with one sentence that says what it shows.

## Download it

Select **Download as a spreadsheet (CSV)**. The file has every section, one after another, separated by a blank line. Open it in any spreadsheet program.

## Good to know

- The report only gathers what DonorDesk already records. It does not calculate new figures, so check any figure you are unsure of against the indicator page.
- The report is available to anyone who can view the project.
