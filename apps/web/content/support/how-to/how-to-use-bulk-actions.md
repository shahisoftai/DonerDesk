# How to Use Bulk Actions

Bulk actions let you make the same decision on many items at once. DonorDesk has several. Where a list has tick boxes, ticking a row brings up a bar with the actions that fit.

## Compliance checklist

1. Open **Reports → Compliance** (or a project's **Reports → Compliance** page) and click **Bulk actions**.
2. Tick the items you want, or click **Select all**.
3. Choose **Start work**, **Resolve**, **Accept risk** or **Not applicable**.
4. Add the shared note (required for Resolve; recommended otherwise) and apply. The note is saved on every selected item.
5. Click **Exit bulk** to leave bulk mode.

## Files to verify

1. Open **Reports → Evidence** (all projects) or a project's **Evidence** tab.
2. Tick the files, or click **Select all N awaiting verification on this page**. A dark bar appears at the bottom of the screen: **n files selected**, with **Verify** and **✕** to clear the selection.
3. Click **Verify**. You are told how many were verified and why any could not be (for example a file you may not verify, or one with a problem).

## Completed activities

On **Plan → Work plan → Completed activities**, click **Select all waiting** (or tick activities), optionally write a note for all of them, and click **Accept n selected**.

## Planned activities

In the **List** view of **Plan → Work plan**, tick planned activities. A panel lets you **Preview move** (shift all by a number of days), **Preview lead** (the same lead for all) or **Preview status** (start them, or cancel them with a reason). Nothing changes until you confirm the preview.

## Flagged statements in a report

In the report editor, the statements tab lets you decide on several flagged statements together (for example **Keep with a note** or **Leave out**) instead of one by one. Use it only when the same reason applies to all of them.

## Indicator values

The indicator grid is a bulk editor. Edit many rows, then press **Save all** to save them in one operation. See [How to update indicator values](/support/how-to/update-indicator-values).

## Imports

To create many records at once, import from Excel or CSV: logframe items, indicators, activities and evidence all have a **Download template** button. See [Data import and export](/support/advanced-features/data-import-export).

## Safety

- Bulk decisions are recorded per item in the audit trail.
- High-severity risk acceptance still needs the right authority.
