# How to Use Bulk Actions

Bulk actions let you make the same decision on many items at once. DonorDesk has three of them.

## 1. Compliance checklist

1. Open **Compliance** (or a project's compliance page) and click **Bulk actions**.
2. Tick the items you want, or click **Select all**.
3. Choose **Start work**, **Resolve**, **Accept risk** or **Not applicable**.
4. Add the shared note (required for Resolve; recommended otherwise) and apply. The note is saved on every selected item.
5. Click **Exit bulk** to leave bulk mode.

## 2. Flagged statements in a report

In the report editor, the statements tab lets you decide on several flagged statements together (for example **Keep with a note** or **Leave out**) instead of one by one. Use it only when the same reason applies to all of them.

## 3. Indicator values

The indicator grid is a bulk editor. Edit many rows, then press **Save all** to save them in one operation. See [How to update indicator values](/support/how-to/update-indicator-values).

## Imports

To create many records at once, import from Excel or CSV: logframe items, indicators, activities and evidence all have a **Download template** button. See [Data import and export](/support/advanced-features/data-import-export).

## Safety

- Bulk decisions are recorded per item in the audit trail.
- High-severity risk acceptance still needs the right authority.
