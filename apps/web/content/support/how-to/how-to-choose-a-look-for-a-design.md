# How to Choose Themes, Fonts, Shapes and Icons

## Theme
Open **Look** and choose a theme. A theme also recolours charts that use the default colours. A colour set you chose yourself is kept.

## Fonts
A font is bundled only if its file ships with DonorDesk; the editor tells you. Files use bundled fonts, so what you see matches what prints.

## Shapes, icons and images
Add **Shape** or **Icon** blocks to decorate. Add a description (alt text) for any image or chart that carries meaning.

## Design check
Before sharing, run the check. It warns about colours too pale to read and many colours without patterns. See [check an infographic](/support/how-to/check-an-infographic).
