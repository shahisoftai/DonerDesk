# How to See the History of Your Results Framework

Every time someone changes the outputs, outcomes, indicators or targets on your logframe, DonorDesk keeps a copy. You can read the history at any time, and a manager can mark a version as the one the donor agreed.

## Read the history

1. Open the project and go to **Logframe**.
2. Select **Framework history**.

Each version has a date and a plain sentence for what changed, for example *"Indicator IND-1: target changed from 100 to 120"*. The newest version is at the top. The page shows the latest 15 versions.

If nothing has changed, no new version is saved.

## Sign off a version

Someone with edit rights on the project can select **Sign off the framework as it is now**. This saves the current framework as a version (if it has changed) and marks it as signed off, with your name and the date. Use this for the framework the donor approved.

Reports approved after this record the framework version they were approved against.

## What the history does not do

- It shows what changed, not who typed each field. The audit trail records who saved each change.
- It does not restore an old target. To go back, edit the indicator to the old value.
