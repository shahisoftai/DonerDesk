# Troubleshooting Storage Issues

## Where is my evidence stored?

Either in **your Google Drive** (link-first, recommended) or in **DonorDesk-managed storage**. Check **Settings → Setup → Connect Google Drive**.

## Google Drive shows "not connected" or access errors

1. Go to **Settings → Setup** and click **Reconnect**.
2. Sign in with the Google account that owns the Drive folders and approve access.
3. Retry the action.

## The project folder is missing

On the project's **Setup** page check **Project workspace folder**. Use **Retry workspace**, or **Repair workspace** if it is partly created.

## I can't see a file I linked

The connected Google account must be able to open it. Share the file with that account, or re-link it.

## "Storage limit reached"

Only DonorDesk-managed uploads count toward your plan (Starter 1 GB, Team 25 GB, Growth 100 GB). Delete files you no longer need (Admin), or use Drive links, which are not charged. See [Plans and limits](/support/account-billing/plans-and-limits).

## Usage looks wrong

Usage is shown in **Settings → Billing**. Refresh after deleting files. If it still looks wrong, email support@donordesk.online.

## Switching storage

The storage choice is made in **Settings → Setup**. Contact support@donordesk.online before changing it if you already have evidence uploaded, so existing files are handled correctly.

## Need help

Email support@donordesk.online with the project name and what you see.
