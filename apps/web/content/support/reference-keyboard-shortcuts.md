# Keyboard Shortcuts

## Report editor

Single-key shortcuts work when you are not typing in a field or the editor. They are ignored if Ctrl, Cmd or Alt is held.

| Key | Action |
|---|---|
| **j** | Next section |
| **k** | Previous section |
| **n** | Next issue |
| **Shift + N** | Previous issue |
| **e** | Edit the selected section |
| **a** | Approve the selected section |
| **?** | Show the shortcut list |

While editing text, standard formatting shortcuts apply | Shortcut | Action |
|---|---|
| Ctrl + B | Bold |
| Ctrl + I | Italic |
| Ctrl + E | Inline code |
| Ctrl + K | Add or edit a link |
| Ctrl + Shift + 8 | Bulleted list |
| Ctrl + Shift + 7 | Numbered list |
| Ctrl + Z / Ctrl + Shift + Z | Undo / redo |

(Use Cmd instead of Ctrl on Mac.)

## Timeline

| Key | Action |
|---|---|
| **← / →** (bar focused) | Move the activity one day |
| **Shift + ← / →** | Change the end date by a day |
| **Save** | Confirm the move; **Esc** cancels |

## Dashboard canvas

| Key | Action |
|---|---|
| **Arrow keys** | Move the chart |
| **Shift + arrow keys** | Resize the chart |

## Anywhere in the app

| Key | Action |
|---|---|
| **Ctrl K** (Mac **⌘K**) | Open **Search or jump to…**: find a project, a file or a page, or run an action (for example **Create a project**, **Record a value, activity, file or expense**, **Invite a person**, **Switch light or dark mode**). **↑ ↓** move, **Enter** runs, **Esc** closes. |
| **?** | Show the shortcut list |
| **G** then **H** | Go to **Home** |
| **G** then **I** | Go to the **Inbox** |
| **G** then **P** | Go to **Projects** |
| **G** then **D** | Go to **Dashboards and infographics** |
| **G** then **R** | Go to **Reports** |
| **G** then **E** | Go to **Evidence** |
| **G** then **S** | Go to **Settings** |
| **R** | Open the **Record** panel |

In the report's text editor **Ctrl K** adds a link, so click outside the text first (or use **Search or jump to…** at the top) to open the search. In the dashboard and infographic editor **Ctrl K** opens the editor's own command list instead, and the app-wide letters (**G**, **R**, **?**) are off there.

The single-key shortcuts work when you are not typing in a field and are ignored while Ctrl, Cmd or Alt is held. You only get the pages and actions your role may use. **On a report's page the report's own shortcuts (above) apply instead**, including **?**; **Ctrl K** still works there.

## Panels and lists

| Key | Action |
|---|---|
| **Esc** | Close a panel (Record, an activity's details, evidence peek, attach files) or a dialog. With several panels open, **Esc** closes the top one; **Back** (←) in its header does the same. |
| **J / K** (or the ▼ ▲ buttons) | In a planned activity's panel, go to the next or previous activity of the list behind it |
